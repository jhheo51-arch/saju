# 033-palace-noble-helper — 궁궐 귀인전

작성일: 2026-09-26  
상태: 구현·자동·빌드·미리보기 검증 완료, 로그인 사용자·참가자 화면 확인 전

## 목적

`03 나의 아바타` 안에서 천을귀인의 전통 계산 결과와 한국적인 도움 관계를 궁궐 이야기로 보여줍니다. 귀인을 운명적인 구원자나 특정 띠의 사람으로 단정하지 않고, 실제 생활에서 도움을 주고받는 모습을 돌아보게 합니다.

## 계산 규칙

1. 일간의 천간을 기준으로 천을귀인 지지 두 글자를 정합니다.
   - 갑·무·경: 축·미
   - 을·기: 자·신
   - 병·정: 해·유
   - 신: 인·오
   - 임·계: 묘·사
2. 계산된 네 기둥의 지지와 두 글자를 비교해 일치한 년주·월주·일주·시주만 표시합니다.
3. 일치한 글자가 없어도 `귀인이 없다`, `귀인복이 없다`고 표현하지 않습니다. 전통 계산표의 한 가지 보조 표시가 직접 보이지 않는다고 안내합니다.
4. 이 계산은 Gemini에 맡기지 않고 이미 계산된 사주 차트에서 결정합니다. 저장 형식은 바꾸지 않습니다.

참고한 계산표:

- https://www.cheoneulbi.com/guide/saju-cheoneulgwiin-noble-force
- https://www.sazu.app/fortune/sinsal/cheoneul-gwiin

## 화면과 문장 규칙

1. 기존 아바타 카드 아래, `04 오늘과 이번 주 운세` 전에 `궁궐 귀인전`을 둡니다.
2. `나의 귀인패`, `궁궐에서 만나는 모습`, `귀인을 알아보는 장면`, `내가 여는 궁문` 순서로 읽습니다.
3. `천을귀인`을 누르면 일간과 지지를 대조하는 전통 보조 표시라는 쉬운 설명을 엽니다.
4. 오행별 궁궐 이야기는 전통 계산과 구분한 창작 설명이며, 선배·동료·소개·조언·실무 도움·고마움 표현처럼 한국 생활에서 익숙한 관계 장면을 사용합니다.
5. 특정 띠·성별·직업을 실제 귀인으로 확정하지 않고, 미래 사건이나 도움의 시기를 예언하지 않습니다.
6. 넓은 화면에서는 두 열, 680px 이하에서는 한 열로 표시합니다. 색만으로 의미를 전하지 않습니다.

## 검증 기록

- 실제 계산 함수와 같은 데이터를 쓰는 임시 로컬 미리보기에서 PC와 375px 화면을 확인했습니다.
- 좁은 화면에서 귀인패 글자가 눌리던 문제를 한 열 배치로 고쳤고, 가로 넘침과 브라우저 오류가 없음을 확인했습니다.
- 비단정 안내는 뜻을 유지하면서 넓은 화면에서 한 줄로 읽히도록 짧게 정리했습니다. 작은 화면은 가로 넘침을 막기 위해 자연스럽게 줄바꿈합니다.
- 안내 문구 보강 검사 6/6, 전체 `npm run check` 171/171과 `npm run build`가 통과했습니다.
- 임시 미리보기 경로는 확인 뒤 삭제했으며, 제작용 빌드에도 포함되지 않습니다.
- 실제 결과는 Google 로그인 뒤에만 열리므로 로그인 사용자 화면과 참가자 직접 확인은 남겨두었습니다.
