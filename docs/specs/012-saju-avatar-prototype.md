# 012-saju-avatar-prototype — 사주 기반 아바타 첫 버전

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 사용 확인 전

## 목적

계산된 사주를 바탕으로 한 판타지 아바타를 결과 화면에 보여줍니다. 참가자가 첨부한 산·소나무·해와 달 그림을 아바타의 배경으로 사용합니다. 캐릭터는 사람일 필요가 없습니다.

## 이번 버전의 규칙

1. 이미 계산된 **일간의 오행**(목·화·토·금·수)에 따라 서로 다른 비인간형 캐릭터 그림과 이름을 고릅니다. 결과를 다시 열어도 같은 사주라면 같은 아바타가 나옵니다.
2. **직업·나이·성별**을 캐릭터 카드에 반드시 표시합니다. 이는 사주로 알아낸 사용자의 실제 직업·나이·성별이 아니라, 캐릭터의 **창작 설정**임을 카드에 분명히 적습니다. 첫 버전의 비인간 캐릭터는 성별을 ‘없음’으로 둡니다.
3. 기존 입력값·계산 결과만 사용합니다. 출생일 원본이나 개인정보를 아바타 그림 생성 서비스에 보내지 않습니다. 이미지 생성은 개발 중 고정된 캐릭터 원화 제작에만 쓰고, 사용자의 사주를 외부 이미지 API로 보내지 않습니다.
4. 첨부 그림은 배경 자산으로 복사해 보존하며 원본은 수정하지 않습니다. 캐릭터 그림은 배경이 투명한 별도 자산으로 넣고 배경 앞에 겹칩니다. 그림 위 텍스트는 피하고, 직업·나이·성별은 읽기 쉬운 별도 정보 영역에 둡니다.
   결과 화면에서는 `03 · 나의 아바타`를 별도 영역으로 두고 이미지와 직업·나이·성별·특징을 나란히 보여줍니다. 기존 오늘의 운세는 `04`로 표시합니다.
5. 기존 사주 풀이, 저장·복원, 로그인, 모바일 화면과 오류 흐름을 유지합니다. 아바타는 저장 형식을 바꾸지 않고 저장된 사주에서 다시 결정합니다.

## 한계와 다음 단계

- 아바타 직업·나이·성별은 전통 사주 감정으로 계산한 속성이 아닙니다. 오행에서 영감을 받은 이야기 설정입니다.
- 사용자 선택으로 성별 표현·직업·의상 등을 바꾸는 기능, 매번 새로운 이미지를 외부 API에서 생성하는 기능은 이번 범위 밖입니다.
- 공개 배포는 하지 않습니다.

## 완료 조건

- 서로 다른 일간 오행에 따라 캐릭터가 바뀌며 같은 사주에서는 안정적으로 같은 캐릭터가 나옵니다.
- 아바타 카드에 직업·나이·성별과 창작 설정이라는 설명이 보입니다.
- 첨부 그림이 실제 배경으로 표시되고 캐릭터 그림은 그 위에 보입니다.
- 저장 결과를 다시 열어도 아바타가 표시되며, 기존 테스트와 빌드가 통과합니다.
- PC·휴대전화 로컬 화면을 확인하고 참가자 직접 확인은 별도로 기록합니다.

## 검증 기록

- 일간 오행별 비인간 캐릭터 원화 5종과 첨부 그림 배경을 추가했습니다. 첨부 그림은 원본과 SHA-256이 같습니다.
- 별도 `03 · 나의 아바타`에 그림·직업·나이·성별·특징·창작 설정 안내를 표시하고 오늘의 운세를 `04`로 이동했습니다. 저장된 사주에서 아바타를 다시 결정하므로 저장 형식은 바뀌지 않았습니다.
- 독립 검사에서 아바타 선택·복원·이미지 투명도·영역 순서를 확인했습니다. 전체 `npm run check` 74/74, `npm run build` 통과했습니다.
- `localhost:3000`의 PC와 휴대전화 너비에서 첨부 배경과 캐릭터, 정보, 순서와 가로 넘침 없음을 확인했습니다. 참가자 직접 사용 확인은 남아 있습니다.
- 최신 변경은 `019-avatar-copy-and-simple-background.md`를 따릅니다. 이 단계의 복잡한 풍경 그림은 원본 파일로 보존하지만 현재 화면의 배경에는 표시하지 않습니다.
