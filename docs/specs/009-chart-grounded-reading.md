# 009-chart-grounded-reading — 질문 입력 제거와 사주 근거 중심 풀이

작성일: 2026-09-23  
상태: 구현·자동 검사 및 로컬 화면 확인 완료, 참가자 사용 확인 전

## 목적

‘요즘 궁금한 점’ 자유 입력을 없애고, 계산된 사주 자체가 개인별 해석의 중심이 되게 합니다. 전문적인 사주 용어와 계산 근거는 유지하되, 풀이 문장은 중학생도 읽을 수 있는 한국어로 작성합니다.

## 이번 범위

1. 화면에서 질문 입력과 질문 답변 카드를 제거합니다. 새 해석 요청은 질문을 Gemini에 보내지 않습니다. 기존 브라우저·계정 저장 결과는 삭제하지 않으며, 옛 질문 답변은 화면에 표시하지 않습니다.
2. 기존 계산기가 낸 일간, 월주, 여덟 글자의 오행 개수를 결과 위에 짧게 보여줍니다. 이 수치는 개인별로 달라지며 Gemini가 만든 추정값이 아닙니다.
3. Gemini에게 일간과 월주, 오행 분포를 실제 값대로 해석하도록 지시합니다. 성향은 일간의 전통적 상징을 쉬운 비유로 풀고, 선택 주제는 다른 계산 근거와 일상 예시를 연결합니다. 오늘의 운세도 단정적 예언 대신 가벼운 행동 제안으로 씁니다.
4. 일간·월주·오행 개수만으로 성격이나 운명을 확정하지 않습니다. 지장간, 십성, 대운 등 지금 계산하지 않는 요소는 개인의 결과인 것처럼 만들어내지 않습니다. 전문 용어는 기존 클릭형 뜻풀이가 있는 것만 씁니다.
5. 모델 응답 형식 오류나 연결 실패 시 가짜 풀이를 대신 내놓지 않고 재시도를 안내합니다. 기존 저장·로그인·오류 흐름을 유지합니다.

## 이번 범위 밖

- 새 십성·지장간·대운 계산, 특정 사건의 날짜 예측
- 궁합, 배포, 데이터베이스 구조 변경
- 옛 저장 결과를 자동 재생성하거나 삭제하는 작업

## 완료 조건

- 화면에 ‘요즘 궁금한 점’ 입력과 답변 카드가 없고, 새 Gemini 요청에도 질문이 없습니다.
- 서로 다른 사주 입력은 서로 다른 계산 근거를 보여줍니다. 일간·월주·오행 개수는 계산 결과와 일치합니다.
- 생성 지침은 일간/월주를 실제 값에 묶고, 쉬운 비유·일상 예시·불확실성 표현을 요구합니다.
- 기존 저장 결과를 읽을 수 있고, 질문 답변이 있더라도 새 화면에 노출하지 않습니다.
- 독립 테스트, 타입 검사, 빌드와 localhost 화면을 확인합니다. 실제 사용자 사용 확인과 풀이의 의미 품질 판단은 별도입니다.

## 검증 기록

- 화면에서 질문 입력과 옛 답변 카드를 제거하고, 계산된 일간·월주·오행 수를 결과 위에 표시했습니다. 일간·월주·오행 용어와 일간 이름은 눌러 뜻을 볼 수 있습니다.
- Gemini에는 원본 생년월일·시간과 질문을 전달하지 않습니다. 성향 본문에 실제 일간, 주제 본문에 실제 월주가 빠지면 결과를 거절합니다. 기존 저장 결과는 삭제하지 않고, 이전 방식의 풀이에는 새 풀이 안내를 표시합니다.
- 독립 테스트 작성자가 새 요청·근거 일치·옛 저장 결과 호환·용어 도움말을 검사했습니다. `npm run check`: 타입 검사와 자동 테스트 64/64 통과. `npm run build`: 통과. `git diff --check`: 오류 없음.
- `localhost:3000`에서 질문란 부재, 근거 영역, 옛 결과 안내를 확인했습니다. 가상 입력 두 건(2000-01-01 12:00, 2005-12-23 08:37)의 실제 Gemini 응답에서 각각 다른 일간·월주가 풀이에 반영되고 질문 답변이 생성되지 않음을 서버 응답으로 확인했습니다. 브라우저에서 새 해석 제출은 기존 브라우저 저장 결과를 교체하지 않기 위해 실행하지 않았습니다. 참가자 직접 사용 확인 전입니다.
