# 004-term-meaning-copy — 위치가 아닌 사주 용어의 뜻 설명

## 목표

단어를 눌렀을 때 ‘어디에 적히는가’보다 ‘사주에서 무엇을 뜻하는가’를 먼저 알려줍니다.

## 이번 범위

1. 천간은 하늘의 기운을 나타낸다고 보는 열 가지 상징이라는 뜻과 갑·을/병·정의 쉬운 예를 설명합니다.
2. 지지는 땅의 기운과 계절·시간을 나타낸다고 보는 열두 가지 상징이라는 뜻을 설명합니다.
3. 일간·음양·십성도 배치나 분류 규칙보다 읽는 의미를 먼저 설명합니다.
4. 기존 팝업 구조와 사주 계산은 변경하지 않습니다. 자연에 빗댄 전통적 상징을 실제 측정값이나 확정적인 성격 진단처럼 쓰지 않습니다.

## 완료 조건

- 천간을 누르면 ‘윗글자’라는 위치 설명 대신 의미와 구체적인 비유가 보입니다.
- 지지를 누르면 ‘아랫글자’라는 위치 설명 대신 의미가 보입니다.
- 용어 데이터 검사, 타입 검사, 빌드와 브라우저 표시가 통과합니다.
