# 047-daily-fortune-cron — 매일 오늘의 운세 준비 작업

작성일: 2026-09-28
상태: 048로 구체화·구현 진행

## 결정 기록

이 문서는 예약 작업의 첫 방향을 기록한 초안입니다. 이후 요구가 구체화되어, 실제 구현 기준은 `048-prepared-daily-fortune-palace-reveal.md`를 따릅니다.

- Vercel Cron은 매일 **한국 시간 오전 9시**에 `/api/cron/daily-fortune`을 호출합니다. UTC 표현식은 `0 0 * * *`입니다.
- 각 로그인 사용자의 저장된 사주 차트를 조회해, 해당 한국 날짜의 운세를 `daily_fortunes`에 미리 생성합니다.
- 오늘의 운세는 생년월일·태어난 시간으로 계산한 사주 차트와 한국 날짜만 사용합니다. 관심 주제·기존 해석·Gemini 호출과 연결하지 않습니다.
- `CRON_SECRET` 인증, 응답 캐시 금지, 실패 사용자만 따로 기록하는 기준은 048에 함께 정의합니다.

## 확인할 점

- Vercel Cron은 운영(Production) 배포에서만 호출됩니다.
- Hobby 요금제에서는 하루 한 번 실행할 수 있으나 실제 호출은 최대 약 59분 늦어질 수 있습니다.
- 배포 전에 Vercel의 Production 환경변수에 `CRON_SECRET`과 Supabase 서비스 역할 키를 직접 등록해야 합니다. 값 자체는 코드·Git·작업일지에 저장하지 않습니다.
