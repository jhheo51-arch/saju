# 021-structured-reading-sections — 근거가 보이는 사주 풀이

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 사용 확인 전

## 목적

성향과 관심 주제 풀이를 한 문단으로만 보여주지 않고, 사용자가 “어떤 계산값을 왜 이렇게 읽었는지”를 쉽게 따라갈 수 있는 구조로 나눕니다.

## 범위

1. 새 Gemini 응답의 성향·관심 주제에는 한 줄 요약과 함께 `계산 근거`, `쉬운 뜻`, `생활 장면`, `균형 있게 볼 점`, `작은 행동`을 각각 받습니다.
2. 성향의 계산 근거에는 실제 일간과 다른 사주 단서 하나 이상을, 관심 주제의 계산 근거에는 실제 일간과 월주를 포함합니다.
3. 서버는 새 구조의 필수 항목·길이·실제 계산값 반영 여부를 검사하며, 빠지거나 맞지 않으면 가짜 결과로 채우지 않고 재시도 오류를 냅니다.
4. 화면은 긴 문단 대신 이름이 붙은 항목으로 보여줍니다. 모바일에서 가로 스크롤 없이 한 열로 읽을 수 있어야 합니다.
5. 예전 브라우저·계정 저장 결과는 삭제하지 않고 기존 한 문단 형태로 계속 표시합니다.
6. 오늘·이번 주 운세, 사주 계산법, 입력 항목, 아바타, 로그인·저장 방식은 이번 개선에서 바꾸지 않습니다.

## 완료 조건

- 새 응답 구조와 화면이 다섯 항목을 모두 표시합니다.
- 구조 일부가 빠지거나 실제 일간·월주 근거가 맞지 않는 새 응답은 거절합니다.
- 예전 저장 형식은 계속 읽을 수 있습니다.
- 관련 독립 테스트, 전체 검사, 빌드와 PC·모바일 화면 확인을 마칩니다.

## 검증 기록

- 성향과 관심 주제에 `계산 근거`, `쉬운 뜻`, `생활 장면`, `균형 있게 볼 점`, `작은 행동`을 필수로 받도록 응답 형식과 화면을 변경했습니다.
- 계산 근거가 실제 일간·월주와 맞지 않거나 다섯 항목 중 하나라도 빠진 새 응답은 거절하며, 예전 한 문단 저장 결과와 새 구조 저장 결과를 모두 복원하는 독립 테스트를 추가했습니다.
- 가상 입력 `2005-12-23 08:37`, 관심 주제 `일`로 실제 Gemini 응답에 다섯 항목과 실제 계산 근거가 포함되는 것을 확인했습니다.
- 로컬 PC·375px 세로·812px 가로 화면에서 항목 배치와 가로 넘침이 없음을 확인했고, 새 결과를 저장한 뒤 다시 열어도 세부 항목이 유지되는 것을 확인했습니다.
- `npm run check`: 100/100 통과. `npm run build`: 통과.
- 참가자의 직접 사용 확인과 공개 배포는 하지 않았습니다.
