# 020-weekly-fortune-no-graph — 오행 칸 그래프 제거와 이번 주 운세

작성일: 2026-09-23  
상태: 구현·자동 및 로컬 화면 확인 완료, 참가자 사용 확인 전

## 목적

큰 오행 8칸 그래프를 결과 화면에서 없애고, 오늘의 운세와 이번 주 운세를 함께 읽게 합니다. 사주 계산 근거의 간단한 글자 수 표시는 유지합니다.

## 범위

1. 독립된 `03` 영역의 오행 칸 그래프와 관련 설명을 제거합니다. `03`은 아바타 카드로 유지하고 `04`는 오늘·이번 주 운세를 담습니다. 아바타와 사주 원자료는 유지합니다.
2. 이번 주는 **한국 시간 월요일~일요일**입니다. 오늘과 같은 요청에서 Gemini가 이번 주 풀이를 함께 만들며, 시작·종료 날짜는 서버가 계산합니다. Gemini에게 주간 날짜 계산을 맡기지 않습니다.
3. 주간 풀이는 계산된 사주 단서와 선택 주제를 연결해 중학생도 이해할 수 있는 짧은 글과 이번 주 실천할 작은 행동 하나를 제시합니다. 특정 요일의 사건·합격·수익·건강 결과는 예언하지 않습니다.
4. 새 해석 응답에는 주간 풀이와 서버가 정한 시작·종료 날짜가 반드시 있어야 합니다. 빠지거나 형식·기간이 틀리면 가짜 글로 채우지 않고 오류를 안내합니다.
5. 이전에 저장한 결과는 삭제하지 않습니다. 과거 결과에 주간 풀이가 없으면 새 해석을 만들면 볼 수 있다는 안내를 표시합니다. 최근 결과 1건 저장 구조와 로그인 방식은 유지합니다.

## 완료 조건

- 결과 화면에서 8칸 그래프가 사라지고 `03` 아바타, `04` 오늘·이번 주 카드가 보입니다.
- 주간 날짜 계산이 주 경계·연말 경계·한국 날짜 기준에 맞습니다.
- 새 응답의 주간 풀이 누락/잘못된 기간은 거절하고 옛 저장 결과는 읽을 수 있습니다.
- 관련 독립 테스트, 전체 검사, 빌드, 로컬 화면을 확인합니다. 참가자 직접 사용 확인은 별도입니다.

## 검증 기록

- 결과 화면에서 8칸 그래프와 관련 설명·스타일을 제거하고 `03`은 아바타, `04`는 오늘·이번 주 카드로 유지했습니다. `02`의 간단한 오행 글자 수 텍스트는 남겼습니다.
- 서버는 한국 날짜에서 월요일~일요일을 계산해 Gemini에 전달합니다. 새 응답의 weekly 누락·잘못된 기간·본문 오류는 거절하고, 이전 저장 결과의 weekly 부재는 허용해 새 해석 안내를 표시합니다.
- 독립 테스트 작성자가 주 경계·연말 경계·오류 응답·옛 저장 복원·화면 구조를 검사했습니다. `npm run check`: 타입 검사와 자동 테스트 86/86 통과. `npm run build`: 통과. `git diff --check`: 공백 오류 없음.
- 가상 입력의 로컬 API 요청에서 `2026-09-21~2026-09-27` 주간 풀이 생성 확인. 기존 브라우저 저장 결과를 바꾸지 않았습니다. PC와 약 374px 모바일 너비에서 그래프 부재, 03/04 카드, 모바일 가로 넘침 없음 확인. 참가자 직접 확인은 남았습니다.
