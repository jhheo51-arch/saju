# 016-five-element-avatar-relations — 단순 오행 아바타와 관계 안내

작성일: 2026-09-23  
상태: 구현·아바타 검증 완료, 전체 검사 대기

## 목적

60갑자마다 새 그림을 만들지 않고 목·화·토·금·수 다섯 아바타만 사용합니다. 첨부한 예시처럼 형태와 색면이 단순한 종이 질감의 궁궐 캐릭터로 다시 만들고, 같은 그림에도 계산된 사주에 따라 서로 다른 궁궐 역할 이야기를 붙입니다.

## 이번 버전의 규칙

1. 아바타는 일간의 오행에 따라 목·화·토·금·수 다섯 장 중 하나를 안정적으로 고릅니다. 같은 사주는 다시 열어도 같은 아바타를 봅니다.
2. 기존 원화와 먼저 만든 단순 원화는 보존하고 궁궐 버전은 `*-palace-v03.png`라는 새 파일로 저장합니다.
3. 새 원화는 투명 배경, 한 명의 전신 캐릭터, 단순한 색면, 부드러운 종이 질감, 굵고 최소화한 얼굴 표현, 조선 궁궐에서 볼 법한 단순 한복을 공통 규칙으로 합니다. 특정 신분을 고정하는 왕관·관모·무기, 글자·문양 설명·풍경·그림자·복잡한 소품은 넣지 않습니다.
4. 결과 카드에는 계산된 일간·월주·오행 글자 수를 사용해 아래 세 가지 창작 내용을 표시합니다.
   - `궁궐 역할`: 오행별 역할 후보 중 사주 글자 조합으로 고른 한 가지
   - `맡은 일`: 일간과 월주의 상징을 궁궐의 구체적인 임무로 연결한 한 문장
   - `함께할 기운`: 내 오행이 과할 때 균형을 돕는 오행과 협력하는 장면 한 문장
5. 관계 대응은 목←수, 목→화, 목의 균형→금 / 화←목, 화→토, 화의 균형→수 / 토←화, 토→금, 토의 균형→목 / 금←토, 금→수, 금의 균형→화 / 수←금, 수→목, 수의 균형→토로 고정합니다.
6. 궁궐 역할은 실제 직업·신분·성별이 아닌 창작 설정이며, 관계 안내도 궁합이나 인간관계를 확정하지 않는 상징적 참고라고 표시합니다. 특정 오행 사람과 반드시 만나거나 피하라고 지시하지 않습니다.
7. 오행 정보는 색만으로 구분하지 않고 오행 이름과 설명을 글자로 함께 보여줍니다. 기존 로그인·저장·풀이·모바일 흐름은 유지합니다.

## 완료 조건

- 새 단순 궁궐 화풍의 투명 PNG 아바타 5장이 별도 파일로 존재하고 화면에서 사용됩니다.
- 아바타 카드에 궁궐 역할·맡은 일·함께할 기운 세 가지와 창작 설정이라는 한계가 보입니다.
- 같은 사주는 같은 역할을 받고, 일부 다른 사주는 같은 오행 그림 안에서도 다른 역할을 받을 수 있습니다.
- 목·화·토·금·수의 균형 관계와 이미지 경로를 자동 검사합니다.
- `npm run check`, `npm run build`가 통과하고 PC·휴대전화 화면을 확인합니다.
- 참가자 직접 확인은 별도로 기록합니다.
