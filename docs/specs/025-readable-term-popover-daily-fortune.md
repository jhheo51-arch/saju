# 025 — 스크롤 없는 용어 설명과 날짜 선택 운세

## 목표

첨부 화면처럼 `일간` 뜻풀이의 문장이 한 줄로 잘려 가로 스크롤해야 하는 문제를 없앤다. `04 이번 주 운세`의 월~일을 선택하면 그 날짜의 짧은 풀이를 같은 카드 안에서 볼 수 있게 한다.

## 화면

- 용어 설명 창은 배지의 줄바꿈 금지 스타일을 물려받지 않는다. 320~375px 휴대전화에서도 문장이 자동으로 여러 줄에 표시되고, 보통 길이의 뜻풀이는 가로·세로 스크롤 없이 읽힌다. 아주 작은 화면에서는 내용이 잘리는 대신 세로 스크롤을 안전장치로 허용한다. `닫기`와 키보드 조작을 유지한다.
- 이번 주 카드에 `한 주 전체`와 월~일 7개 날짜를 누를 수 있는 단추로 제공한다. 선택한 날짜를 색만이 아니라 눌림 상태로도 알린다. 날짜를 누르면 카드의 제목·본문이 그 날짜의 풀이로 바뀐다. 다른 날짜를 누르거나 `한 주 전체`를 누르면 같은 자리에서 내용이 교체된다. 카드 안에 별도 가로 스크롤을 만들지 않는다.
- 기존 저장 결과에 날짜별 풀이가 없으면 기존 주간 요약을 보여주고, 새 해석을 하면 날짜별 풀이가 생긴다고 안내한다. 날짜별 운세를 임의로 만들어 표시하지 않는다.

## Gemini 결과와 실패 조건

- 기존 사주 계산값과 선택 주제를 바탕으로, 주간 요약 외에 월~일의 `weekly.days` 7개를 `{date, body}` 형태로 받는다. 각 `date`는 서버가 계산한 주간 날짜와 정확히 일치해야 하며 중복이 없어야 한다. 각 `body`는 중학생이 이해할 짧은 한국어 1~2문장이다.
- 특정 날짜의 사건·취업·연애 성사·수익·건강 결과를 예언하지 않는다. 7일의 문장이 모두 같은 말을 반복하지 않도록 날짜마다 살펴볼 점을 다르게 고른다. 날짜별 간지나 별도 사주를 계산한 척하지 않는다.
- 새 Gemini 응답에 날짜가 빠지거나 중복되거나, 기간 밖 날짜·빈 문장·지나치게 긴 문장이 있으면 전체 응답을 거절하고 기존 재시도 오류를 보여준다. 가짜 결과를 채우지 않는다.
- `today` 날짜의 주간 항목은 서버가 검증된 `today.body`와 일치시킨다. 기존 저장 결과에는 `weekly.days`가 없어도 복원하고, 새 결과에서는 7일 목록을 최근 결과와 함께 저장한다.

## 범위 밖

- 요일별 운세 점수, 정확한 미래 사건, 그날의 사주를 새로 계산한 것처럼 보이는 표시.
- 공개 배포와 저장 방식 변경.

## 수용 기준

- [x] 휴대전화 화면에서 용어 설명의 가로 스크롤이 없고 설명 문장과 닫기 버튼을 읽고 누를 수 있다.
- [x] 새 결과의 7일 중 다른 날을 눌렀을 때 그날의 문장으로 바뀌고, 한 주 전체로 돌아올 수 있다(구현·자동 검사, 새 결과의 참가자 화면 조작 전).
- [x] 날짜 단추는 키보드로도 작동하며 선택 상태를 읽을 수 있다(네이티브 버튼·접근성 상태 자동 검사, 실사용 전).
- [x] 잘못된 날짜별 Gemini 응답은 거절되고 이전 저장 결과는 정상 복원된다.
- [x] 자동 검사·빌드·로컬 화면 확인을 마치고 참가자 직접 확인은 별도로 남긴다.

- 독립 테스트 보강 후 `npm run check`: 타입 검사와 117/117 테스트 통과. `npm run build` 통과.
- 임의 예시 입력의 로컬 API: HTTP 200, 2026-09-21부터 27일까지 날짜별 풀이 7개 확인. 개인의 실제 생년월일은 새 테스트에 사용하지 않음.
- `localhost:3000` 기존 결과에서 `일간` 설명을 열어 375px 화면 기준 팝업 `scrollWidth`와 `clientWidth`가 같고 설명·닫기 버튼이 모두 보이는 것을 확인. 주간 카드에도 가로 넘침 없음.
- 사용자 저장 결과는 변경하지 않음. 오래된 저장 결과는 날짜별 풀이가 없다는 안내를 표시함. 새 결과에서 날짜를 누르는 실제 참가자 확인은 남음. 배포하지 않음.
