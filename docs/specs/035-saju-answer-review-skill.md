## 목적

## 범위

1. `.agents/skills/saju-answer-reviewer`에 자동 선택 가능한 Codex 스킬을 둡니다.
2. 실제 답변 JSON에서는 일간·월주·음양 분포·계절 근거의 정확한 포함 여부와 서로 모순되는 다른 계산값의 동시 표기를 자동 검사합니다.
3. 상투적인 보완형 관계 문장, 확정적인 미래 예측, 관계 답변의 관찰 행동 부족을 자동 검사합니다.
4. 현재 상황과 원하는 방향이 답변에 그대로 보이지 않으면 사람이 의미 반영 여부를 확인할 수 있도록 주의로 표시합니다.
5. 프롬프트와 코드 검토에서는 계산·개인화·안전·작은 행동·개인정보 기준표를 사용합니다.
6. 스킬은 사주를 다시 계산하거나 누락된 생년월일·출생시간을 추측하지 않습니다.
