# 037-saju-evaluation-harness — 사주 답변 평가 하네스

작성일: 2026-09-26  
상태: 구현·자동 검증 완료

## 목적

프롬프트나 파서를 바꿀 때 좋은 답변은 유지되고 잘못된 답변은 계속 거절되는지, 대표 사례 전체를 한 명령으로 반복 검사합니다. 테스트·문서·답변 검사 스킬로 흩어진 피드백 장치를 하나의 실행 흐름으로 연결합니다.

## 범위

1. `evals/saju-answer-cases.json`에 통과·근거 오류·상투 표현·확정 예언·관계 행동 부족·맥락 누락 사례를 둡니다.
2. 기존 `.agents/skills/saju-answer-reviewer/scripts/check_answer.py`를 유일한 답변 품질 판정기로 재사용합니다.
3. `evals/run_saju_evals.py`가 모든 사례를 격리해 실행하고 기대 상태·오류 코드와 비교합니다.
4. 실행 결과를 콘솔과 `evals/reports/latest.json`에 남기며 실패가 하나라도 있으면 종료코드 1을 반환합니다.
5. `npm run harness`가 타입·자동 테스트와 사주 답변 평가를 한 번에 실행합니다.
6. GitHub Actions가 push와 PR에서 하네스와 빌드를 실행합니다.
7. 전체 흐름은 `docs/diagrams/saju-harness-workflow.html`의 접근 가능한 프로세스 다이어그램으로 보여줍니다.

## 제외

- 기본 하네스는 Gemini를 실시간 호출하지 않습니다. 비용·응답 변동 없이 프롬프트와 품질 규칙의 회귀를 잡는 것이 목적입니다.
- 사람의 취향 판단이나 실제 사용자 만족도를 자동 점수 하나로 대체하지 않습니다.

## 완료 조건

- `npm run eval:saju`와 `npm run harness`가 성공합니다.
- 잘못된 기대값을 넣으면 평가 명령이 실패합니다.
- 전체 자동 검사와 프로덕션 빌드가 통과합니다.
- 워크플로우 다이어그램이 입력, 생성, 검증, 판정, 리포트, 개선 루프를 구분해 보여줍니다.
