# 024-personal-context-selects — 현재 상황과 원하는 방향 선택

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 사용 확인 전

## 목적

같은 사주와 관심 주제를 고른 사람에게 똑같은 이야기를 하지 않도록, 사용자가 현재 상황과 풀이에서 원하는 방향을 짧게 선택하고 주제 풀이에 반영합니다.

## 범위

1. 입력 화면에 `현재 상황`과 `원하는 방향` 선택 항목을 각각 하나씩 추가합니다.
2. 현재 상황은 `방향을 찾는 중`, `선택을 앞둠`, `변화를 준비함`, `꾸준히 이어가는 중`, `잠시 쉬며 균형을 찾는 중`에서 고릅니다.
3. 원하는 방향은 `강점 이해`, `선택 기준`, `관계와 대화`, `작은 행동`, `무리하지 않는 균형`에서 고릅니다.
4. 선택값은 허용된 짧은 문구로만 서버에 전달하며, 생년월일·출생시간처럼 원본 개인정보를 Gemini에 보내지 않는 기존 규칙을 유지합니다.
5. Gemini는 두 선택을 `관심 주제`의 생활 장면·균형·작은 행동과 오늘·이번 주 행동에 반영합니다. 선택값을 사주 계산 근거로 쓰거나 사용자가 고르지 않은 사정을 추측하지 않습니다.
6. 결과 화면에 실제 반영한 두 선택을 표시하고, 새 결과를 저장했다가 다시 열어도 유지합니다.
7. 이전 저장 결과와 선택 항목이 없는 이전 요청은 계속 사용할 수 있습니다.

## 완료 조건

- 입력 화면에서 두 항목을 각각 하나씩 선택할 수 있고, 선택하지 않으면 무엇을 고를지 알려줍니다.
- 임의 문자열이나 한쪽만 있는 잘못된 선택값은 서버가 거절합니다.
- Gemini 전달 자료와 지침에 검증된 두 선택만 포함됩니다.
- 결과·브라우저 저장·계정 저장에서 두 선택이 보존되며 예전 결과도 계속 열립니다.
- 관련 독립 테스트, 전체 검사, 빌드와 PC·모바일 화면 확인을 마칩니다.

## 검증 기록

- 허용된 현재 상황 5개와 원하는 방향 5개만 서버가 받도록 검사하고, 한쪽 누락·임의 문자열은 Gemini 호출 전에 거절합니다. 선택이 없던 이전 요청은 계속 처리합니다.
- 검증된 선택값과 화면 문구가 Gemini 자료·지침에 포함되고, 사주 계산 근거에 섞지 않으며 선택하지 않은 사정을 추측하지 않도록 지시하는 독립 테스트를 추가했습니다.
- 새 결과의 `reading.context`를 브라우저·계정 저장에서 복원하고, 선택 정보가 없는 이전 저장 결과도 유지하는 것을 확인했습니다.
- 가상 입력 `2005-12-23 08:37`, 관심 주제 `일`, 현재 상황 `중요한 선택을 앞두고 있어요`, 원하는 방향 `선택 기준을 얻고 싶어요`로 실제 Gemini 생성을 확인했습니다. 선택 내용이 주제의 생활 장면·균형·작은 행동에 반영됐고 새로고침 뒤에도 선택 요약이 유지됐습니다.
- PC와 375px 모바일 화면에서 필수 선택 두 개와 결과 요약을 확인했고, 모바일 가로 넘침이 없었습니다.
- `npm run check`: 117/117 통과. `npm run build`: 통과. `git diff --check`: 내용 오류 없음(기존 줄바꿈 방식 경고만 있음).
- 참가자의 직접 사용 확인과 공개 배포는 하지 않았습니다.
