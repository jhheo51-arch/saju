# 031-five-element-colors — 오행 고유색 표시

작성일: 2026-09-26  
상태: 구현·자동 검증 완료, 로그인 후 참가자 화면 확인 전

## 목적

첨부 참고 이미지처럼 계산 근거의 오행 그래프에서 목·화·토·금·수를 각기 다른 색으로 빠르게 구분할 수 있게 합니다.

## 화면 규칙

1. 현재 5축 방사형 그래프와 실제 계산값은 유지합니다. 상생·상극 화살표나 별도 원형 오행도는 이번 범위에 추가하지 않습니다.
2. 목은 청록, 화는 적색, 토는 황금빛 갈색, 금은 중성 회색, 수는 짙은 청회색 계열을 사용합니다.
3. 그래프의 축 이름과 점, 아래의 정확한 값 배지에 같은 오행 색을 일관되게 적용합니다.
4. 축 이름 뒤에는 옅은 원형 바탕을 두어 첨부 이미지의 인상을 반영하되 기존 그래프의 데이터 면적을 가리지 않습니다.
5. 색은 보조 단서입니다. `목(木)` 같은 이름과 `목 1` 같은 실제 개수, 화면 읽기 도구용 설명을 그대로 유지합니다.
6. 휴대전화 화면에서도 원형 바탕·이름·값이 잘리거나 겹치지 않아야 합니다.

## 완료 조건

- 다섯 오행의 축 이름·점·값 배지가 각각 정해진 색으로 표시됩니다.
- 색을 보지 못해도 이름·한자·개수로 같은 정보를 읽을 수 있습니다.
- 기존 수치, 축 순서, 0개와 4개 초과 처리, 요약 문장은 바뀌지 않습니다.
- 독립 테스트, 전체 검사, 배포용 빌드, PC·모바일 화면을 확인합니다.

## 검증 기록

- 목 `#14796d`, 화 `#b43b3b`, 토 `#8a6400`, 금 `#58616c`, 수 `#2d536f`를 축 이름·데이터 점·정확한 값 배지에 공통 적용하고, 각 축 이름 뒤에 같은 계열의 옅은 원형 바탕을 추가했습니다.
- 텍스트와 옅은 바탕의 명암비는 목 `4.65:1`, 화 `5.02:1`, 토 `4.89:1`, 금 `5.55:1`, 수 `7.06:1`로 모두 일반 글자 기준 `4.5:1` 이상입니다.
- 독립 테스트 5개에서 오행별 식별자와 색 토큰, 원형 바탕·점·축 이름·값 배지의 연결, 한글·한자·개수·화면 읽기 설명 유지, 0개·4개 초과 값, 모바일 축소·줄바꿈을 확인했습니다.
- 전체 자동 검사 `149/149`, 배포용 빌드, 변경 형식 검사가 통과했습니다.
- 실제 결과 화면은 로그인 후에만 열리므로 참가자의 PC·모바일 화면 확인은 남았습니다. 외부 배포는 하지 않았습니다.
