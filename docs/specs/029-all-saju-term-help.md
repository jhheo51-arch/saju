# 029 · 실제 네 기둥 이름과 사주 용어 설명

## 목표

`무자·을유`처럼 사용자의 계산 결과에서 나온 두 글자 이름을 포함해, 화면에 표시되는 어려운 사주 용어를 그 자리에서 눌러 이해할 수 있게 합니다.

## 화면 규칙

1. `천간·지지·일간·년주·월주·일주·시주·오행·음양·십성`, 십성 이름 열 개, 천간 오행 이름 열 개는 기존의 클릭형 설명을 사용합니다.
2. 계산된 년주·월주·일주·시주의 두 글자 이름은 고정된 60개 문장을 따로 만들지 않고, 실제 차트의 윗글자·아랫글자·한자·오행으로 설명합니다.
3. 두 글자 이름은 성향·주제 풀이의 제목과 본문·다섯 세부 항목, 아바타의 궁궐 이야기, 오늘·날짜별·이번 주 운세, 운세 근거 배지에서 같은 방식으로 설명됩니다.
4. 계산 원자료의 `년주·월주·일주·시주` 이름도 각각 태어난 해·달·날·시간의 두 글자라는 뜻을 엽니다.
5. 설명은 성격이나 미래를 확정하지 않고, 별도 긴 용어 사전 영역을 추가하지 않습니다.
6. 모든 설명은 마우스·터치·키보드로 열고 `닫기` 단추로 닫을 수 있습니다.

- [x] 설명 창에 두 한자, 윗글자의 오행·자연 비유, 아랫글자의 지지·오행이 표시됩니다.
- [x] 년주·월주·일주·시주의 뜻을 계산 원자료에서 열 수 있습니다.
- [x] 자동 검사와 제작용 빌드가 통과합니다.
- [x] 375px 화면에서 설명 창이 가로로 넘치지 않습니다.

## 구현·검증 기록

- 성향·관심 주제·아바타·오늘/이번 주 운세에서 실제 네 기둥 이름을 같은 설명 단추로 연결했습니다.
- `을유은`처럼 조사가 어색해지지 않도록 받침에 맞춰 `은/는`을 선택합니다.
- `일주일` 속 `일주`는 사주 용어로 잘못 인식하지 않도록 자동 연결 대상에서 제외하고, 계산 원자료의 정확한 `일주` 이름만 설명 단추로 표시합니다.
- `npm run check` 135/135, `npm run build` 통과. PC와 375×812 화면에서 `무자` 설명을 열어 확인했고 브라우저 오류는 0건입니다.
