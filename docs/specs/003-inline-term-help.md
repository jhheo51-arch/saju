# 003-inline-term-help — 사주 용어를 눌러 뜻 보기

## 목표

결과 화면을 길게 만드는 별도 용어 사전을 제거하고, 실제로 표시된 사주 단어를 눌렀을 때만 쉬운 뜻을 보여줍니다.

## 이번 범위

1. `처음 보는 사주 단어` 영역과 카드 목록을 결과 화면에서 제거합니다.
2. 계산된 사주 원자료에 나오는 `천간`, `지지`를 누르면 해당 자리에서 기존 쉬운 설명이 펼쳐지고, 다시 누르면 접힙니다.
3. 클릭 가능한 단어는 밑줄과 키보드 초점 표시로 구분합니다. 마우스 없이도 열고 닫을 수 있습니다.
4. 이미 작성한 기본 용어·십성 설명 데이터는 유지합니다. 향후 실제 풀이에 해당 용어가 등장할 때 같은 방식으로 연결합니다. 지금은 십성을 개인별 결과처럼 임의로 표시하지 않습니다.

## 범위 밖

- 개인별 십성 계산, 실제 사주 해석, 로그인, 배포

## 완료 조건

- 결과의 별도 사전 영역이 없어지고, 원자료의 천간·지지를 누를 때만 뜻이 보입니다.
- 원자료의 계산값과 입력 흐름은 그대로 작동합니다.
- 키보드로 용어 설명을 열고 닫을 수 있고, 좁은 화면에서 설명이 잘리지 않습니다.
- 타입 검사, 관련 테스트, 빌드와 실제 브라우저 동작을 확인합니다.

## 검증 기록

- 2026-09-23: 독립 테스트 작성자가 별도 사전 영역 제거 및 천간·지지 설명 연결을 검사하도록 `tests/glossary.test.ts`를 보강했습니다.
- `npm run check`: 타입 검사와 자동 테스트 24/24 통과.
- `npm run build`: Next.js 빌드 통과. 배포는 하지 않았습니다.
- 브라우저에서 별도 사전 영역이 없고, 원자료의 천간을 클릭하면 설명 창이 뜨며 닫기 버튼으로 사라지는 것을 확인했습니다. 지지는 키보드 Enter로 열고 Escape로 닫았습니다. 좁은 브라우저 화면에서도 원자료와 설명이 잘리지 않았습니다. 실제 휴대전화에서의 참가자 사용 확인은 아직입니다.
