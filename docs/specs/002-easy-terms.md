# 002-easy-terms — 어려운 사주 용어 쉬운 설명

## 목표

사주 용어를 숨기지 않고, 처음 보는 사람도 뜻을 바로 이해할 수 있게 합니다.

## 이번 범위

1. 결과 화면에서 천간·지지·일간·오행·음양·십성을 짧은 말로 설명합니다.
2. 편관·비견·편인·정인·식신을 포함한 십성 열 가지를 모두 사전 형태로 보여줍니다.
3. 계산된 네 기둥은 윗글자(천간)와 아랫글자(지지)를 나눠 표시합니다.
4. 십성 사전은 **공통 설명**임을 분명히 합니다. 사용자의 사주에 어떤 십성이 있는지 계산하거나 성격을 단정하지 않습니다.

## 범위 밖

- 개인별 십성 산출 및 사주 해석
- 로그인, 결과 저장, AI 연결, 배포

## 완료 조건

- 단어와 쉬운 뜻이 함께 보이고, 모든 설명은 휴대전화 너비에서 줄바꿈되어 읽을 수 있습니다.
- 원자료의 천간·지지 분리가 기존 계산값과 일치합니다.
- 공통 사전이 개인 맞춤 풀이로 오인되지 않도록 안내합니다.
- 타입 검사, 관련 테스트, 브라우저 표시를 검증합니다.

## 용어 기준

- 한국민족문화대백과사전 「사주」: https://encykorea.aks.ac.kr/Article/E0025957
- 김만태, 「명리학의 육신과 십성」 관련 학술 자료, 『한국학』 2020: https://www.accesson.kr/ksq/assets/pdf/41143/journal-43-2-109.pdf
