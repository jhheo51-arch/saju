# 044-personalized-question-structure — 질문 답변 개인화 구조

작성일: 2026-09-26  
상태: 완료

## 요구사항

- 답변에 고민의 핵심, 세 문단 본문, 선택 기준 두 가지, 반대 모습, 작은 행동을 구분한다.
- 현재 상황과 원하는 방향을 계산 근거와 섞지 않으면서 생활 장면과 기준에 반영한다.
- 작은 행동은 시점·횟수·대상 중 하나를 드러낸다.
- 출생시간 제한 풀이에서는 시주를 추측하지 않는다.

## 검증 기록

- 새 응답에 고민 초점, 서로 다른 선택 기준 두 개, 주의 행동이 모두 필요하고 중복 기준을 거절하는 독립 테스트를 추가했습니다.
- 화면 렌더와 저장 호환성, 출생시간 제한 지침, 질문 답변 저장 선택을 함께 검사했습니다.
- 전체 테스트 195/195, 사주 평가 10/10, 전체 하네스와 빌드가 통과했습니다. 실제 로그인 Gemini 말맛 평가는 사람 평가에 남깁니다.
