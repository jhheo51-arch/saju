# 043-account-history-privacy — 계정 기록과 개인정보 제어

작성일: 2026-09-26  
상태: 코드·마이그레이션·자동 검증 완료, 실제 DB 적용과 두 계정 확인 전

## 요구사항

- 최근 해석을 최신순 최대 10건 저장·복원한다.
- 결과별 삭제와 전체 삭제를 제공한다.
- 원본 생년월일·출생시간·질문 원문·토큰은 저장하지 않는다.
- 질문 답변은 사용자가 체크한 경우에만 저장한다.
- RLS는 `auth.uid() = user_id`를 유지하고 다중 행용 기본키·인덱스를 추가한다.

## 검증 기록

- 최신순 최대 10건 조회, 새 행 저장과 초과 정리, 개별·전체 삭제, 질문 답변 갱신, 개인정보 미저장을 독립 테스트로 확인했습니다.
- 다중 행 기본키·주제 제약·인덱스·10건 정리 트리거를 `20260926000100_expand_saju_result_history.sql`에 작성했습니다.
- Supabase CLI와 접근 토큰·DB 비밀번호가 이 환경에 없어 실제 프로젝트에는 적용하지 못했습니다. 적용 후 `docs/checklists/google-account-isolation.md`로 확인해야 합니다.
- 전체 하네스 195/195와 빌드는 통과했습니다.
