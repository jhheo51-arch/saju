# 042-birth-time-confidence — 출생시간 정확도별 제한 풀이

작성일: 2026-09-26  
상태: 완료

## 요구사항

- 정확히 앎, 대략적인 시간대, 모름을 선택한다.
- 정확하지 않으면 임의의 시주를 만들지 않고 년주·월주·일주 6글자만 계산한다.
- 제한 풀이와 밤 11시 전후의 일주 불확실성을 화면·Gemini 지침·저장 결과에 남긴다.
- 시주가 필요한 아바타 역할·귀인전·간이 용신은 제한 풀이에서 표시하지 않는다.

## 검증 기록

- 정확한 시간은 4기둥·8글자, 대략·모름은 동일한 3기둥·6글자이며 입력 시각을 남기지 않는 독립 테스트를 추가했습니다.
- 로그아웃 화면에서 세 선택과 개인정보 안내를 확인했습니다. 제한 결과는 자동 렌더 계약으로 확인했습니다.
- `npm run harness`의 전체 테스트 195/195, 사주 평가 10/10, `npm run build`, `git diff --check`가 통과했습니다.
