# 055-visible-palace-fortune-reveal — 문 안 운세 표시와 넓은 양문

작성일: 2026-09-28  
상태: 구현·자동 검사·Production 빌드 완료, 참가자 화면 확인 전

## 문제

문짝을 열어도 문 배경층이 안쪽 운세 카드를 계속 덮어, 사용자는 빈 청록 화면만 봅니다. 또한 문 너비가 좁아 새 양문의 디테일과 안쪽 운세를 함께 읽기 어렵습니다.

## 해결

- 열린 상태에서는 양쪽 문짝만 앞으로 남기고, 중앙 문 배경·이음선은 투명 처리한다.
- 안쪽 운세 카드는 열린 문 중앙에서 보이며, 문짝보다 뒤·문 배경보다 앞인 읽기 순서를 유지한다.
- 문 무대의 최대 너비를 560px, 비율을 5:4로 넓힌다. 작은 화면에서는 부모 너비를 넘지 않는다.
- 버튼의 `aria-expanded`, 44px 이상 조작 영역, 열린 운세 제목으로의 초점 이동, 모션 줄이기 처리는 유지한다.

## 완료 조건

- 문 클릭 후 색상·숫자·한 줄 운세가 중앙에서 눈에 보인다.
- 넓은 화면에서 양문이 560px까지 넓어지고, 작은 화면에서 가로 넘침이 없다.
- 자동 테스트, 품질 하네스, Production 빌드를 통과한다.
