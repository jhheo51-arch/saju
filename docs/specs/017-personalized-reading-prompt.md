# 017-personalized-reading-prompt — 사주 풀이 프롬프트 개인화

작성일: 2026-09-23  
상태: 구현·자동 및 합성 입력 확인 완료, 참가자 사용 확인 전

## 목적

계산된 이름을 문장에 끼워 넣는 수준에서 벗어나, 개인의 실제 사주 근거가 선택한 관심 주제의 일상 장면에 어떻게 연결되는지 중학생도 이해할 수 있게 설명합니다.

## 이번 범위

1. 기존 Gemini 서버 프롬프트만 다듬습니다. 사주 계산, 입력, 응답·저장 형식은 바꾸지 않습니다.
2. 성향에서는 실제 일간의 자연 비유와 계산된 다른 근거 하나를 연결해 가능한 해석과 구체적 일상 장면을 씁니다. 주제 풀이에서는 실제 월주와 일간을 함께 연결해 선택한 주제에 맞는 상황·작은 행동을 씁니다.
3. `일간/월주를 적었다`에서 끝나지 않게 **계산 근거 → 그 뜻을 쉬운 말로 → 생활 속 예 → 시도할 행동**의 흐름을 요구합니다. 같은 문장을 다른 사람의 사주나 다른 주제에도 그대로 붙일 수 있으면 다시 구체화하도록 지시합니다.
4. 계산되지 않은 십성·대운 등은 추측하지 않고 오행 개수만으로 성격·운명 강약을 단정하지 않습니다. 직업·건강·관계·돈의 결과와 시기를 예언하지 않습니다.
5. 기존 중학생 수준의 짧은 한국어, 전문 용어 설명, 응답 형식 검사, API 키 보안과 오류 처리는 유지합니다.

## 범위 밖

- 모델 교체, 추가 개인정보 수집, 새 사주 계산 규칙, 저장된 과거 결과 자동 재생성, 배포

## 완료 조건

- 가짜 Gemini 요청을 이용한 독립 테스트가 실제 일간·월주와 선택 주제에 관한 개인화 지침을 확인합니다.
- 기존 자동 검사와 빌드가 통과합니다.
- 실제 Gemini 출력의 문장 품질은 참가자가 새 풀이를 생성해 별도로 판단합니다. 이전에 저장된 한 건은 프롬프트만 바꿔도 자동으로 바뀌지 않습니다.

## 검증 기록

- Gemini 서버 지침에 성향의 일간+추가 실제 단서, 주제 풀이의 월주+일간, 계산 근거→쉬운 뜻→생활 장면→작은 행동 흐름을 추가했습니다. 원본 생년월일·시간은 보내지 않고 계산·저장·응답 형식은 변경하지 않았습니다.
- 구현하지 않은 낱글자 한글 읽기나 새로운 사주 이름을 추측하지 말고, 제목에서도 성격을 단정하지 않도록 지시했습니다.
- 구현하지 않은 독립 테스트 작성자가 주제별 개인화 지침과 개인정보 제외를 검사했습니다. 관련 테스트 10/10, 전체 `npm run check` 79/79, `npm run build` 통과했습니다.
- 가상 생년월일 두 건의 로컬 API 요청으로 서로 다른 일간·월주·선택 주제가 실제 Gemini 문장에 반영되는 것을 확인했습니다. 가상 입력만 사용했고 브라우저에 저장된 사용자 결과는 바꾸지 않았습니다. 문장 품질은 생성마다 달라지므로 참가자 직접 확인은 남아 있습니다.
