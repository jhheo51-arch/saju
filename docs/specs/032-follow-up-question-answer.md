# 032-follow-up-question-answer — 결과 아래 궁금한 점 답변

작성일: 2026-09-26  
상태: 구현·자동 검증 완료, 로그인 사용자 화면 확인 전

## 목적

오늘·이번 주 운세를 읽은 사용자가 현재 사주 결과를 바탕으로 궁금한 점 하나를 이어서 묻고, 직접적인 답과 작은 행동을 별도 영역에서 확인합니다.

## 범위

1. 결과의 `04 오늘과 이번 주 운세` 아래에 `05 궁금한 점 답변` 영역을 둡니다.
2. 로그인했고 완성된 사주 결과가 있는 사용자만 200자 이내 질문을 보낼 수 있습니다.
3. 답변은 현재 결과의 실제 일간·월주·음양 분포·월지 계절 구간과 선택 주제, 현재 상황, 원하는 방향을 사용합니다. 네 계산 단서를 모두 포함한 `이번 답변의 근거`가 없거나 다른 사람의 단서를 쓰면 답변을 거절합니다. 사주를 다시 계산하거나 입력에 없는 개인정보를 추측하지 않습니다.
4. 정확한 미래 날짜, 합격·연애 성사·수익·질병을 예측하지 않고 직접 답변과 지금 해볼 작은 행동을 구분합니다.
5. 질문 원문은 답변 생성을 위해 Gemini에 전달하지만 계정에는 저장하지 않습니다. 답변과 작은 행동만 최근 결과 1건에 함께 저장해 새로 열어도 볼 수 있게 합니다.
6. 질문 로딩·오류를 전체 해석과 분리해 기존 결과를 지우지 않습니다.
7. 연애·인간관계 질문은 `부족한 부분을 채워주는 사람`처럼 누구에게나 맞는 보완형 문장으로 끝내지 않습니다. 대화 속도, 감정 표현, 갈등 뒤 회복, 경계 존중, 결정 방식처럼 실제로 살펴볼 행동을 두 가지 이상 제시합니다.
8. 입력 아래의 Gemini 전달·미래 예측 안내 문구는 제거하고 실제 답변 품질로 신뢰를 보여줍니다. 새 답변은 결론, 두 가지 이상 사주 단서의 연결 이유, 현재 상황의 구체적인 모습, 도움이 되는 선택 기준, 조심할 반대 모습을 3문단·6~9문장·260~800자로 설명합니다. 연애·관계 답변은 관찰 행동 세 가지 이상으로 잘 맞는 모습과 주의할 모습을 대비합니다.
9. 근거는 `일간 · 월주 · 음양 · 계절` 계산값만 한 줄에 표시하고 설명은 답변 본문에서 자연스럽게 풀어냅니다.

## 완료 조건

- 빈 질문·200자 초과·로그아웃 요청을 서버와 화면에서 거절합니다.
- 올바른 질문은 답변과 작은 행동을 반환하고 `05` 영역에 표시합니다.
- 새 답변은 실제 사주 단서 네 가지를 근거로 표시하며, 근거가 빠지거나 다른 사주의 값이면 성공으로 표시하지 않습니다.
- 새 답변이 260~800자 또는 3문단 형식을 벗어나면 거절하되, 기존 저장 답변은 계속 복원합니다.
- 답변 저장에 실패해도 현재 화면의 답변은 유지하고 저장 실패를 알립니다.
- 전체 자동 검사, 빌드, PC·모바일 화면 확인을 마칩니다.

## 검증 기록

- 질문 전용 `/api/question`은 로그인 토큰과 현재 저장 결과를 검사한 뒤 Gemini에 계산된 사주 단서·주제·맥락과 질문만 전달합니다. 원본 생년월일·출생시간·인증 토큰·API 키는 전달하지 않습니다.
- 독립 검사자가 안내 문구 제거, 접근성 연결, 새 답변의 160~520자 경계, 기존 저장 답변 호환, 상세 답변 지시, 관계 행동 비교, 응답 길이 설정을 다루는 보강 검사 8개를 추가했습니다.
- 개인화 보강 후 답변에는 실제 일간·월주·음양 분포·계절 구간을 정확한 한 줄로 담은 근거가 필수이며, 설명을 덧붙이거나 하나라도 현재 결과와 다르면 HTTP 502로 거절합니다. 관계 질문에는 대화·감정·갈등 회복·경계·결정 방식 중 관찰 가능한 행동을 세 가지 이상 연결합니다.
- `npm run check`: 타입 검사와 자동 테스트 174/174 통과. `npm run build`: 통과. `git diff --check`: 공백 오류 없음.
- 로그아웃 상태의 로컬 API 호출은 HTTP 401과 로그인 안내를 반환했습니다. 현재 브라우저 세션이 만료되어 로그인 사용자의 실제 Gemini 답변 화면 확인은 참가자에게 남아 있습니다.
