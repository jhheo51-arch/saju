# 036-narrative-saju-reading — 상담처럼 이어지는 사주 풀이

작성일: 2026-09-26  
상태: 구현·자동 검증 완료, 로그인 사용자 화면 확인 전

## 목적

계산 단서를 억지로 나열하는 답변 대신, 핵심 성향과 현재 고민이 하나의 이야기처럼 이어지는 구체적인 풀이를 제공합니다. 특정 서비스의 문구나 비공개 프롬프트를 복제하지 않고, 친근한 상담형 서술과 풍부한 생활 장면만 참고합니다.

## 범위

1. 전체 성향·관심 주제·오늘·이번 주·후속 질문 프롬프트에 같은 말투 원칙을 적용합니다.
2. 풀이 전 계산값에서 핵심 흐름과 서로 당기는 두 면을 먼저 고른 뒤, `계산 단서 → 쉬운 의미 → 실제 생활 장면 → 선택 기준` 순으로 설명합니다.
3. `함께 보면`, `떠올릴 수 있어요`, `참고했어요` 같은 안전 문구를 반복해 분량을 채우지 않습니다. 과장된 예언 없이도 상담자가 직접 짚어주는 자연스러운 한국어를 사용합니다.
4. 후속 질문의 근거는 설명문이 아닌 `일간 · 월주 · 음양 · 계절` 한 줄로 고정하고, 본문은 3개의 짧은 문단으로 나눕니다.
5. 관계 질문은 잘 맞는 모습과 경계할 모습을 실제 대화·갈등·결정 행동으로 대비합니다.
6. 근거 줄 안의 용어 버튼이 각각 새 줄로 깨지지 않도록 근거 내용을 하나의 인라인 영역으로 묶습니다.
7. 기존 저장 결과는 형식을 바꾸거나 삭제하지 않고 그대로 표시합니다.

## 완료 조건

- 두 Gemini 경로에 상담형 서술 원칙과 금지 표현이 반영됩니다.
- 새 후속 답변은 3문단, 6~9문장, 260~800자로 검증됩니다.
- 새 근거는 정확한 네 계산값만 한 줄로 표시됩니다.
- 기존 저장 답변은 계속 복원됩니다.
- 독립 테스트, 전체 검사, 빌드와 화면 확인을 마칩니다.

## 검증 기록

- 전체 해석과 후속 질문에 상담형 서술 순서, 반복 금지 표현, 장점이 과할 때의 반대 모습, 실제 생활 장면과 선택 기준을 추가했습니다.
- 후속 질문은 정확한 근거 한 줄과 3문단·260~800자만 받으며, 기존 저장 답변은 옛 형식 그대로 복원합니다.
- 독립 검사에서 근거 뒤에 설명을 덧붙여도 통과하던 결함을 발견해 정확한 한 줄만 허용하도록 수정했습니다. 관련 해석·질문 검사 23/23, 화면 레이블 검사 13/13을 통과했습니다.
- 전체 `npm run check` 174/174, `npm run build`, `git diff --check`를 통과했습니다.
- 현재 브라우저가 로그아웃 상태라 새 Gemini 답변의 실제 로그인 화면 확인은 남았습니다.
