# 026 · 일간·월주 카드의 글자 구조 배지

## 목표

`이번 풀이의 근거` 오른쪽에 있는 일간·월주 카드의 큰 내부 여백을 줄이고, 기존 풀이·아바타·운세와 겹치지 않는 계산 정보를 짧게 보여줍니다.

## 화면 규칙

1. 일간 카드에는 계산된 실제 `한자·음양·오행`을 작은 배지로 표시합니다.
2. 월주 카드에는 계산된 실제 `윗글자·아랫글자`를 각각 한자·한글 읽기·오행 순서로 표시합니다.
3. 배지는 새로운 성격·미래 해석을 만들지 않고 현재 차트 값만 사용합니다.
4. 각 배지의 글자는 한 줄로 유지하고, 공간이 좁으면 배지 묶음이 다음 줄로 이동합니다.
5. 오른쪽 두 카드는 그래프 높이를 똑같이 나누지 않고 내용 높이로 표시해 카드 내부의 빈 공간을 줄입니다.
6. `일간·월주·음양·오행`은 기존의 클릭형 쉬운 뜻 보기를 유지합니다.

## 완료 확인

- [x] 서로 다른 사주에서도 일간 한자·음양·오행과 월주 두 글자가 실제 계산값대로 바뀝니다.
- [x] PC와 375px 작은 화면에서 배지가 잘리거나 카드 밖으로 넘치지 않습니다.
- [x] 전체 자동 검사와 제작용 빌드가 통과합니다.
- [ ] 참가자가 실제 화면을 확인합니다.

## 구현 및 확인 기록

- 일간은 실제 천간 한자와 천간 순서에 따른 음양, 계산된 오행을 표시합니다.
- 월주는 실제 윗글자·아랫글자를 한자·한글 읽기·오행으로 나눠 표시합니다.
- 오른쪽 두 카드는 같은 높이로 강제로 늘리지 않고 내용 높이에 맞춰 가운데 배치했습니다.
- `npm run check` 118/118과 `npm run build`가 통과했습니다.
- 로컬 PC, 375px 세로, 812×375 가로 화면에서 배지 줄바꿈·가로 넘침·브라우저 오류 없음을 확인했습니다.
