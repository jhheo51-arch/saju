# 013-topic-labels-and-hero-copy — 주제 이름과 제목 설명 정리

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 사용 확인 전

## 요청

- 제목 아래 설명이 넓은 화면에서 마지막 글자만 다음 줄로 떨어지지 않게 합니다. 휴대전화에서는 작은 글씨나 가로 잘림 없이 자연스럽게 줄을 바꿉니다.
- 주제 이름을 `돈 → 재물`, `친구관계 → 인간관계`로 바꿉니다.
- `나 자신` 선택지를 없애고 `건강`을 추가해 전체 9개를 유지합니다.

## 데이터·안전 기준

- 이미 저장된 `money`, `friends` 값은 그대로 사용하고 표시 이름만 변경합니다. 새 건강 주제는 `health` 값으로 구분합니다.
- 예전 `self` 결과는 브라우저·계정에서 읽을 수 있게 유지하지만, 새 입력이나 새 해석 요청에서는 더 이상 선택할 수 없습니다. 저장 결과를 삭제하거나 새 주제로 바꿔 표시하지 않습니다.
- 건강 풀이는 휴식과 생활 리듬을 돌아보는 재미·자기성찰 내용으로 제한합니다. 사주로 질병, 건강 상태, 치료 효과를 예측하거나 의료 조언을 제공하지 않습니다.

## 완료 조건

- 넓은 화면에서 제목 설명은 한 줄이고, 휴대전화에서는 화면 밖으로 잘리지 않으며 읽기 쉬운 크기로 줄바꿈합니다.
- 화면에 9개 주제가 한 번씩 나타나고, 재물·인간관계·건강을 고를 수 있으며 ‘나 자신’은 새 선택지에 없습니다.
- 서버와 Gemini의 주제 목록에 `health`가 있고 새 `self` 요청은 거절합니다. 기존 `self` 저장 결과는 복원할 수 있습니다.
- 자동 검사·빌드·로컬 화면을 확인합니다. 참가자 사용 확인은 별도입니다.

## 검증 기록

- `npm run check`: TypeScript 검사와 자동 테스트 70/70 통과.
- `npm run build`: 프로덕션 빌드 통과.
- 로컬 화면: `localhost:3000`의 1280px 화면에서 소개 문구 한 줄, 375px 화면에서 잘림 없는 두 줄과 가로 넘침 없음 확인. 주제 선택 화면에서 9개 항목과 재물·인간관계·건강 표시 확인.
- 기존 `self` 저장 결과 복원과 새 `self` 요청 거절은 자동 테스트로 확인. 새 건강 해석의 실제 Gemini 응답과 참가자 직접 사용 확인은 아직 하지 않음.
