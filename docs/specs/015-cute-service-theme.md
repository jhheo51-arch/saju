# 015-cute-service-theme — 사주 서비스의 귀여운 분위기

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 사용 확인 전

## 목적

참가자의 후속 요청에 맞춰 아바타뿐 아니라 서비스 전체를 친근하고 귀여운 분위기로 다듬습니다. 최신 색상 요청에 맞춰 기존의 차분한 청록·적갈·금색과 글꼴, 사주 계산·풀이·로그인 기능은 유지합니다.

## 이번 범위

- 제목, 계정, 입력, 주제 선택, 결과, 아바타, 용어 도움말을 둥근 카드와 부드러운 그림자·밝은 바탕으로 연결합니다.
- 의미 있는 글은 밝은 표면 위 진한 색으로 남겨 읽기 쉽게 합니다. 선택·초점 상태는 색상만으로 구분하지 않습니다.
- 아바타에 쓰는 첨부 그림은 수정하지 않습니다. 큰 움직임이나 자동 재생 애니메이션을 넣지 않습니다.
- 기존 청록·적갈·금색에서 밝은 혼합색을 만들고, 현재 글꼴을 유지합니다.

## 완료 조건

- PC와 휴대전화에서 카드·버튼·주제 선택이 한결같이 둥글고 친근한 느낌을 줍니다.
- 선택·오류·로딩, 키보드 초점, 결과의 읽기 쉬움과 가로 넘침 방지가 유지됩니다.
- 자동 검사와 빌드, 로컬 화면 확인 결과를 기록합니다. 참가자 직접 사용 확인은 별도입니다.

## 검증 기록

- `app/cute-theme.css`를 기존 스타일 다음에 적용해 제목·계정·입력·주제·결과·아바타·도움말의 모서리와 그림자, 밝은 바탕을 통일했습니다. 기존 일곱 색상과 글꼴은 유지했습니다.
- 독립 검증에서 주제 선택 테두리·배경, 키보드 초점선, 화면 축소 규칙, 자동 움직임 줄이기 설정을 확인했습니다.
- 전체 `npm run check` 74/74, `npm run build` 통과했습니다. PC 약 1521px와 휴대전화 약 390px 화면에서 카드·버튼·아바타·결과 순서를 확인했고 가로 넘침은 없었습니다.
- 사용자가 직접 선택하거나 실제 휴대전화에서 조작한 결과는 아직 확인하지 않았습니다.
