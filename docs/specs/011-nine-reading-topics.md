# 011-nine-reading-topics — 관심 주제 9개

작성일: 2026-09-23  
상태: 구현·자동 검사 및 로컬 화면 확인 완료, 참가자 사용 확인 전

## 목적

기존 연애·일·돈 3개에 친구관계·가족·공부·진로·취미·나 자신을 더합니다. 사용자가 고른 주제에 맞는 풀이가 나오고, 작은 화면에서도 쉽게 하나를 선택할 수 있어야 합니다.

## 확정된 아홉 주제

| 주제 | 풀이 초점 |
|---|---|
| 연애 | 마음 표현과 대화 |
| 일 | 협업과 일하는 방식 |
| 돈 | 소비와 계획 습관 |
| 친구관계 | 친구와의 거리·대화 |
| 가족 | 가족과의 소통 |
| 공부 | 배우고 정리하는 방식 |
| 진로 | 관심 분야를 탐색하는 방식 |
| 취미 | 즐거움을 발견하고 꾸준히 하는 방식 |
| 나 자신 | 감정·휴식·자기이해 |

참가자가 위 구성을 확인했습니다.

## 동작과 안전 기준

1. 화면의 주제 선택, 서버 입력 검사, Gemini 응답 형식, 저장 결과의 주제 검사에 같은 9개 값이 적용됩니다. 기존 3개 저장 결과도 계속 열립니다.
2. Gemini에는 선택한 주제 이름과 초점만 전달합니다. 기존 계산 근거인 일간·월주, 중학생도 읽는 말투, 예시, 불확실성 표현은 유지합니다.
3. 진로는 취업 시점이나 합격을 예언하지 않습니다. 돈은 수익을 보장하지 않고, 나 자신은 의료·정신건강 진단을 하지 않습니다. 모델 실패나 주제 불일치 시 가짜 결과를 저장하지 않습니다.
4. 휴대전화에서는 선택 카드가 좁거나 겹치지 않고, 키보드와 터치로 한 개를 고를 수 있어야 합니다.

## 이번 범위 밖

- 아홉 주제 각각의 별도 상세 페이지, 여러 주제 동시 선택, 궁합, 새 사주 계산법
- 데이터베이스 구조 변경, 배포

## 완료 조건

- 화면에 정확히 9개 주제가 보이고 한 개를 선택해 요청할 수 있습니다.
- 9개 모두 클라이언트·서버에서 같은 값으로 허용되며, 선택한 주제와 다른 Gemini 응답은 거절합니다.
- 기존 3개 주제 저장 결과와 로그인·오류·재시도 흐름이 유지됩니다.
- 자동 검사, 빌드, 로컬 화면을 확인하고 참가자 직접 확인은 별도로 기록합니다.

## 검증 기록

- 아홉 주제의 화면 선택값·라벨·풀이 초점을 한 곳에서 관리하고 입력·Gemini 응답·저장 검사에 연결했습니다. 기존 세 주제의 저장 결과는 그대로 읽습니다.
- 작은 화면에서는 두 열 선택 카드로 표시합니다. `localhost:3000`에서 아홉 개의 이름과 설명이 겹치지 않는 것을 확인했습니다. 기존 브라우저 저장 결과를 덮지 않기 위해 화면에서 새 결과 제출은 하지 않았습니다.
- 독립 테스트 작성자가 9개 주제 선택, 입력·서버 응답, 브라우저·계정 저장/복원, 주제별 생성 지침과 불일치 응답 거절을 검사했습니다. 최종 `npm run check`: 타입 검사와 테스트 69/69 통과. `npm run build`: 통과.
- 가상 입력으로 실제 Gemini에 ‘나 자신’, ‘친구관계’를 요청했습니다. ‘나 자신’은 바로 성공했고, ‘친구관계’는 첫 응답의 형식 검사가 실패해 502 재시도 안내를 받았습니다. 한 번 다시 요청했을 때 정확한 주제와 일간·월주가 포함된 풀이가 성공했습니다. 모델 문장 품질은 매번 사람의 확인이 필요합니다.
