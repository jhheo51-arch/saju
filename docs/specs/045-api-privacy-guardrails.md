# 045-api-privacy-guardrails — 인증·요청 제한·실계정 확인

작성일: 2026-09-26  
상태: 코드·자동 검증 완료, 실제 계정 확인 전

## 요구사항

- 인증된 사용자별로 해석은 분당 5회, 질문은 분당 10회로 제한한다.
- 제한 응답은 429와 `Retry-After`를 반환한다.
- 오류·평가 자료에 토큰, 원본 생년월일·출생시간을 기록하지 않는다.
- 실제 Google 계정 두 개로 로그인·복귀·계정 분리·삭제를 확인할 체크리스트를 제공한다.
- 체크리스트는 `docs/checklists/google-account-isolation.md`를 사용한다.

## 검증 기록

- 사용자·기능별 요청 창, 만료 후 재허용, API의 429·`Retry-After`, 큰 본문 선제 거절을 독립 테스트로 확인했습니다.
- 전체 하네스 195/195와 빌드는 통과했습니다.
- 실제 Google 계정 A/B의 로그인 복귀와 RLS 분리는 참가자 계정이 필요해 체크리스트 확인이 남았습니다.
