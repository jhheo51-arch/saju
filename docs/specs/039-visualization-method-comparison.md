# 039-visualization-method-comparison — 시각화 방식 3종 비교

- 작성일: 2026-09-26
- 상태: 완료

## 목적

같은 하네스 워크플로우를 Data, Figma, 공개 GitHub 스킬의 세 방식으로 실제 제작하고 레퍼런스 적합성을 비교한다.

## 범위

1. Data 방식은 600×296 측정 좌표 SVG를 기본안으로 두고, 세 방식의 검토 루브릭을 CSV와 차트로 기록한다.
2. Figma 방식은 편집 가능한 FigJam 플로차트로 만든다.
3. GitHub의 `c0ng-web/codex-skill` 저장소에 공개된 `diagram-maker`를 검사·설치하고 독립 실행형 SVG를 만든다.
4. 레퍼런스 유사도, 편집성, 정확한 배치 제어, 유지보수성, 접근성을 비교한다.
5. 사용자 레퍼런스와의 유사도를 최우선으로 하여 Data 측정 SVG를 프로젝트 기본 시각화로 유지한다.

## 완료 기준

- 세 방식의 결과 또는 편집 가능한 결과물이 존재한다.
- 비교 점수가 실제 사용 통계가 아닌 검토 루브릭임을 명시한다.
- 로컬 HTML/SVG가 구조 검사와 브라우저 렌더링을 통과한다.
- 전체 하네스와 프로덕션 빌드가 통과한다.

## 검증

- Data 비교 CSV·HTML/SVG 구조 및 브라우저 렌더링 확인
- 편집 가능한 Figma FigJam 생성 확인
- `diagram-maker` 전역 설치와 독립 HTML/SVG 구조 및 브라우저 렌더링 확인
- 독립 관련 테스트 4/4, 전체 테스트 185/185, 사주 평가 7/7 통과
- `npm run harness`, `npm run build`, `git diff --check` 통과
