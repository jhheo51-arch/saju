# 040-reference-harness-visual — 첨부 레퍼런스형 하네스 그림

- 작성일: 2026-09-26
- 상태: 완료

## 목표

기존 비교 차트와 오른쪽 시스템 설명 패널을 기본 그림에서 제거하고, 사용자가 다시 제공한 작은 교육용 인포그래픽의 구성과 밀도를 직접 따른다.

## 완료 기준

- 436×267 캔버스에서 흰 종이와 짙은 외곽 배경을 사용한다.
- 상단은 사람 아이디어 → `harness.md` → 에이전트 → 구현 결과 흐름과 파란 `AGENTS.md` 정책 카드를 표시한다.
- 하단은 캐릭터, `evals.json`, `npm run harness`, FAIL 회귀, PASS 완료를 표시한다.
- 원본 캐릭터를 복제하지 않고 단순 SVG 도형으로 새로 그린다.
- 외부 폰트·스크립트·이미지 의존성 없이 접근 가능한 SVG로 제공한다.
- 브라우저 시각 검사, 자동 테스트, 하네스와 빌드를 통과한다.

## 검증

- 실제 브라우저에서 436×267 렌더링과 레퍼런스형 구도 확인
- SVG XML 파싱 및 외부 의존성 부재 확인
- 독립 관련 테스트 6/6, 전체 테스트 187/187, 사주 평가 7/7 통과
- `npm run harness`, `npm run build`, `git diff --check` 통과
