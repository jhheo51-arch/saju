# 023-compact-element-radar — 계산 근거의 오행 방사형 그래프

작성일: 2026-09-23  
상태: 구현·자동 및 로컬 화면 검증 완료, 참가자 직접 확인 전

## 목적

`이번 풀이의 근거`에 한 줄로 표시하던 목·화·토·금·수 글자 수를 작은 5축 방사형 그래프로 바꿔, 오행의 상대적인 분포를 한눈에 봅니다.

## 범위

1. 기존 `03` 독립 영역의 큰 8칸 그래프는 되살리지 않습니다. 방사형 그래프는 사용자가 가리킨 `02` 계산 근거 카드의 오행 항목 안에만 배치합니다.
2. 축 순서는 목·화·토·금·수이며 값은 `chart.elements`의 실제 글자 수를 사용합니다. 합계는 기존 계산대로 8입니다.
3. 기본 축 최댓값은 4개이고 실제 값이 4보다 크면 그 값까지 자동으로 늘립니다. 정확한 값은 각 오행 이름 옆과 그래프 아래 목록에 글자로도 표시합니다.
4. 색만으로 값을 구분하지 않습니다. SVG 제목·설명과 글자 목록을 제공해 화면 읽기 도구에서도 다섯 값을 읽을 수 있게 합니다.
5. 별도 차트 패키지는 추가하지 않고 반응형 SVG로 구현합니다. 기존 풀이·아바타·운세·저장 형식은 바꾸지 않습니다.

## 완료 조건

- 한 줄 오행 숫자 대신 5축 방사형 그래프가 보입니다.
- 다섯 값과 축 순서가 계산 결과와 일치하며 0과 4 초과 값도 안전하게 표시됩니다.
- PC와 작은 화면에서 잘리지 않고 가로 스크롤이 생기지 않습니다.
- 정확한 값이 글자로도 보이고 화면 읽기 도구용 설명이 있습니다.
- 관련 독립 테스트, 전체 검사, 빌드와 로컬 화면을 확인합니다.

## 검증 기록

- 별도 차트 패키지 없이 `ElementRadar` SVG 컴포넌트를 만들고, `chart.elements`를 목·화·토·금·수 순서로 표시했습니다. 기본 바깥선은 4개이며 실제 최댓값이 더 크면 자동으로 늘어납니다.
- 독립 테스트 작성자가 실제 React 정적 렌더링으로 값 전달, 축 순서, 0개, 4개 초과 확장, SVG 제목·설명, 글자 목록, 기존 02→03→04 순서를 검사했습니다.
- `npm run check`: 타입 검사와 자동 테스트 100/100 통과. `npm run build`: 통과. `git diff --check`: 공백 오류 없음.
- 로컬 PC 화면에서 방사형 도형과 다섯 축·정확한 값 목록을 확인했습니다. 작은 화면 검사에서는 그래프가 300px로 줄고 브라우저 적용 폭 500px에서 문서 가로 넘침이 없었습니다.
- 참가자 직접 확인은 아직 받지 않았습니다.
