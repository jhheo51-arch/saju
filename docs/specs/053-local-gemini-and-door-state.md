# 053-local-gemini-and-door-state — 로컬 해석 연결과 궁궐 문 상태 복구

작성일: 2026-09-28  
상태: 구현 완료 (참가자 화면 확인 전)

## 문제

- 로컬 개발 환경에는 Vercel의 Gemini 비밀키를 다시 내려받을 수 없어, 해석 재시도에서 Gemini 연결 설정 오류가 표시됩니다.
- 저장된 열린 문 상태는 있으나, 문 그림의 열린 상태와 분리되어 문짝이 닫힌 채로 보일 수 있습니다.
- 기존 CSS 그림은 사용자가 지정한 단청 궁궐문 원화의 질감과 구성이 아닙니다.

## 해결

- 로컬 개발에서만 명시된 운영 API로 해석 요청을 중계합니다. 운영 배포는 중계하지 않고 Vercel 환경변수를 그대로 사용합니다.
- 열린 문 상태를 무대와 문 그림에 함께 적용해 재방문·새로고침 뒤에도 안쪽 운세가 열린 모습으로 보입니다.
- 사용자가 첨부한 단청 궁궐문 원본을 `public/palace-door-dancheong-v01.png`으로 보존해 양쪽 문짝 배경으로 사용합니다. 문을 열면 두 반쪽이 갈라지고, 가운데 안쪽에 오늘의 운세를 표시합니다.

## 완료 조건

- 로컬에서 Gemini 키 오류 없이 로그인한 해석 재시도를 수행할 수 있다.
- 열린 문 상태에서는 문짝이 열리고 안쪽 운세가 보인다.
- 닫힌 문은 첨부 단청 원화의 전체 모습을 유지하고, 열림 전후에 문짝과 운세의 상태가 일치한다.
- Production 환경과 Cron 보안에는 개발 중계가 적용되지 않는다.
- TypeScript, 자동 테스트, 품질 하네스, Production 빌드가 통과한다.
