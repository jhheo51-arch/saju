# 049-daily-fortune-result-flow — 결과 화면의 오늘 운세와 주간 선택 복구

작성일: 2026-09-28  
상태: 구현·자동 검사 완료, 로그인 화면 확인 대기

## 목표

로그인한 사용자가 `나의 사주 해석 보기`를 누르면, 해석 결과 흐름 안에서 오늘의 운세를 준비하고 바로 읽습니다. 오늘의 운세는 기존처럼 궁궐 문이 열린 카드로 보여 주며, 저장된 색상과 추천 숫자를 반드시 함께 표시합니다. 이번 주 운세는 월요일부터 일요일까지 눌러 읽는 기존 디자인으로 되돌립니다.

## 오늘의 운세 흐름

1. 로그인 사용자가 사주 정보를 제출하면 `/api/daily-profile` 호출과 해석 요청을 함께 시작합니다.
2. 결과 영역에서 `오늘의 운세를 궁궐에 준비하고 있어요.`를 표시합니다.
3. 응답을 받으면 같은 사용자·한국 날짜에 저장된 오늘 운세를 궁궐 문이 열린 상태로 즉시 표시합니다.
4. 열린 카드에는 제목, 본문, 오늘의 한 걸음, 색상, 추천 숫자가 들어갑니다.
5. 이후 다시 방문해도 같은 저장 운세와 열린 카드·색상·숫자를 복원합니다. 오늘 운세 생성 기준은 기존대로 계산된 사주 차트와 한국 날짜뿐입니다.

## 이번 주 운세 복구

- 주간 카드 상단에 `한 주 전체`와 월~일 날짜 버튼을 표시합니다.
- `한 주 전체`는 주간 제목·요약·이번 주의 한 걸음을 표시합니다.
- 날짜를 누르면 해당 요일의 짧은 설명을 같은 카드에서 표시합니다.
- 날짜 행에는 오늘 표시와 절기 정보를 유지합니다.
- 이전에 저장된 해석처럼 날짜별 정보가 없으면 주간 요약은 보여 주되, 새 해석을 만들면 날짜 선택을 사용할 수 있다고 안내합니다.

## 완료 조건

- 제출 직후 결과 흐름에서 준비 문구 다음 열린 궁궐 카드가 표시된다.
- 카드와 기존 오늘 카드 모두 저장된 색상·추천 숫자를 표시한다.
- 월~일 버튼, 한 주 전체, 주간 행동 제안, 날짜별 설명을 사용할 수 있다.
- TypeScript 검사, 자동 테스트, Production 빌드가 통과한다.
- 실제 로그인 상태에서 참가자가 한 번 확인한다.
