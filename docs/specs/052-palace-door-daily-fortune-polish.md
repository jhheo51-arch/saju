# 052-palace-door-daily-fortune-polish — 궁궐 문 안 오늘 운세

작성일: 2026-09-28  
상태: 구현·자동 검사·운영 빌드 완료, 로그인 화면 확인 대기

## 목표

오늘의 운세는 궁궐 문을 열었을 때 문 안쪽에서 한 줄로 읽습니다. 문은 기와 처마, 현판, 금빛 테두리, 문고리를 갖춘 궁궐 문으로 표현합니다.

## 개인화 규칙

- 색과 숫자는 일간 하나로 고정하지 않고, 사주 오행 분포에서 상대적으로 적은 기운의 우선순위와 한국 날짜 순환을 함께 사용합니다.
- 같은 사주·같은 날짜에는 같은 결과를 반환합니다.
- 기존 저장 행에는 새 `palace-door-v2` 식별값이 없으므로, 오늘 다시 조회할 때 새 추천 규칙으로 안전하게 갱신합니다.

## 완료 조건

- 궁궐 문을 열면 색·숫자·한 줄 운세가 문 안쪽에 표시된다.
- 문 밖에는 같은 운세 본문이나 행동 문구를 중복 표시하지 않는다.
- 색·숫자는 사주 분포와 날짜에 따라 달라지고, 저장된 행에도 반영된다.
- 키보드 접근, 44px 이상 버튼, `prefers-reduced-motion` 설정을 유지한다.
- TypeScript, 자동 테스트, 품질 하네스, Production 빌드가 통과한다.
