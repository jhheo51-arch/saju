# 028-daily-fun-cues — 오늘의 색과 숫자

작성일: 2026-09-23  
상태: 구현·관련 검증 완료, 전체 검사 대기

## 목적

오늘 운세 카드가 옆의 긴 주간 카드 높이에 맞춰 늘어나 생기는 빈 공간을 줄이고, 오늘 가볍게 참고할 색상과 숫자를 보여줍니다.

## 범위

1. 오늘 카드와 이번 주 카드는 각자 내용 높이만큼 표시합니다.
2. 오늘 카드에 `오늘의 재미 포인트`로 색상 이름·색상 견본·1~9 숫자를 표시합니다.
3. 같은 사주와 날짜에는 같은 값이 나오며 날짜가 달라지면 바뀔 수 있습니다.
4. 색만으로 정보를 전달하지 않고 색상 이름을 함께 표시합니다.
5. 실제 행운을 보장하거나 미래를 예측하는 값이 아니라는 재미용 안내를 표시합니다.

## 완료 조건

- 오늘 카드 아래의 큰 빈 공간이 줄어듭니다.
- 오늘의 색과 숫자가 한눈에 보입니다.
- 작은 화면에서도 칩이 잘리거나 가로로 넘치지 않습니다.
- 관련 검사, 전체 검사, 빌드와 로컬 화면을 확인합니다.
