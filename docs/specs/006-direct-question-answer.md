# 006-direct-question-answer — 궁금한 점에 먼저 답하기

작성일: 2026-09-23  
상태: 구현·자동 검사 완료, 참가자 화면 확인 전

## 해결할 문제

사용자가 ‘언제 취직할 수 있을지 궁금해’라고 적어도 현재 결과는 일하는 성향만 이야기할 수 있습니다. 질문은 Gemini에 전달되지만, 결과에 직접 답하는 자리가 없고 질문 반영 여부를 검사하지 않기 때문입니다.

## 이번 개선

1. 질문을 적었다면 기존 세 카드보다 앞에 **‘궁금한 점에 대한 답’** 카드를 보여줍니다. 카드는 질문에 대한 짧은 답과 지금 해볼 작은 행동 하나로 구성합니다. 질문을 적지 않았다면 이 카드는 보이지 않습니다.
2. Gemini는 사주 계산값을 설명하는 역할만 유지합니다. 질문에 직접 답하되 중학생도 읽을 수 있는 짧고 구체적인 한국어로 씁니다. 한 문장에 한 가지 생각을 담고, 어려운 용어가 필요하면 승인된 용어만 사용합니다. 행동 제안에는 일상적인 예시 하나를 포함합니다.
3. ‘언제 취직/취업/입사하나요?’처럼 **시점을 묻는 질문**에는 계산되지 않은 날짜·월·연도를 만들어내지 않습니다. 사주만으로 정확한 취업 시점을 알 수 없다는 답을 먼저 보여주고, 선택 주제에 맞는 작은 준비 행동을 제안합니다. 다른 시점 질문에도 정확한 날짜를 알 수 없다는 원칙을 적용합니다.
4. 질문이 있는데 Gemini 응답에 답변 또는 행동 제안이 없거나 형식이 틀리면 결과를 실패로 처리하고 재시도하게 합니다. 기존 성향·주제·오늘 운세 형식 검사도 유지합니다. 단, 모든 답변의 의미가 완벽하게 질문에 맞는지 자동으로 증명하지는 못합니다.
5. 최근 결과 한 건 저장 방식은 유지합니다. 원본 질문을 `localStorage`에 새로 저장하지 않고, 검증된 답변과 행동 제안만 저장합니다. 이전 형식으로 저장된 결과는 그대로 읽되 질문 답변이 없는 옛 결과임을 알립니다.

## 이번 범위 밖

- 대운·세운 등 새로운 시기 계산이나 취업 날짜 예측
- 질문 의도 전반에 대한 완전한 의미 검사와 자동 재생성
- 로그인·서버 저장·배포

## 완료 조건

- 취업 시점 질문을 입력하면 맨 앞 카드가 ‘정확한 시점은 알 수 없다’는 직접 답과 실행 가능한 작은 행동을 보여줍니다. 근거 없는 특정 날짜는 보이지 않습니다.
- 질문이 없는 경우에는 기존 세 카드가 그대로 작동합니다.
- 질문이 있는데 답변 필드가 빠진 모델 응답은 저장·표시하지 않고 재시도를 안내합니다.
- 기존 결과 저장·복원, 사주 용어 클릭 설명, 모바일 가독성, 입력 오류·Gemini 오류가 유지됩니다.
- 자동 테스트와 `localhost` 화면에서 질문 있음/없음의 성공 및 실패 흐름을 확인합니다. 참가자 직접 사용 확인은 별도입니다.
