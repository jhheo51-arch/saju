# 046-expanded-answer-evaluation — 자동·사람 답변 평가 확장

작성일: 2026-09-26  
상태: 자동 평가 완료, 20건 사람 평가 점수 기록 전

## 요구사항

- 자동 판정기는 허위 명리 계산, 반복 문장, 모호한 행동을 추가 검사한다.
- 사람 평가 사례는 20개 이상이며 동일 사주의 맥락 변형과 의료·투자·시기 경계 질문을 포함한다.
- 사람 평가는 구체성·납득도·도움 정도·불쾌감을 같은 척도로 기록한다.
- 하네스 자체 검사가 사례 수와 평가 기준 연결을 확인한다.

## 검증 기록

- 자동 사례를 7건에서 10건으로 늘려 허위 계산·반복 문장·모호한 행동을 각각 실패 사례로 고정했습니다. 사주 평가 10/10이 통과했습니다.
- 동일 사주 맥락 변형, 서로 다른 사주, 출생시간 미상, 시기·의료·투자 경계가 포함된 20건 사람 평가 자료와 네 평가 척도를 추가했습니다.
- `check:harness`가 사례 수와 척도 연결을 검사하며 전체 하네스 195/195와 빌드가 통과했습니다.
- 실제 Gemini 결과에 대한 사람 점수 입력은 로그인 실호출 뒤 진행해야 하므로 완료 전입니다.
