# 001-prototype-flow — 사주 서비스 화면 흐름 프로토타입

## 목표

현재 사주 계산 기능을 유지하면서, PRD의 입력과 결과 화면 순서를 클릭해 확인할 수 있게 합니다.

## 이번 범위

1. 양력 생년월일과 출생시간을 입력하고 연애·일·돈 중 하나를 선택합니다.
2. “요즘 궁금한 점”은 선택 입력이며 최대 200자입니다.
3. 제출하면 기존 `lib/saju` 계산 결과를 얻고, 성향 카드 → 선택한 주제의 풀이 → 오늘의 운세 자리 순서로 보여줍니다.
4. 세 영역은 **해석 준비 중**이라는 안내만 보여줍니다. 사람마다 다른 성향·운세 문장을 만들거나 임의로 채우지 않습니다.
5. 기존 사주의 네 기둥과 계산 방법은 별도로 펼쳐 볼 수 있습니다.
6. 날짜·시간·주제가 잘못되면 오류를 보여주고 이전 계산 결과를 숨깁니다.

## 범위 밖

- 로그인, 결과 저장, 친구·연인 궁합
- 실제 사주 해석과 LLM API 연결
- 결제, 전문가 상담 연결, 배포

## 완료 조건

- 정상 입력과 세 주제에서 계산과 결과 영역 표시가 작동합니다.
- 질문이 없어도 작동하고, 입력한 질문은 주제 풀이 영역에서 확인할 수 있습니다.
- 잘못된 입력과 200자 초과 질문은 기존 검증 규칙으로 거절됩니다.
- 휴대전화 너비에서 가로 스크롤 없이 입력과 결과를 읽고 키보드로 조작할 수 있습니다.
- 기존 사주 계산 테스트와 타입 검사가 통과하고, 브라우저에서 정상·오류 흐름을 확인합니다.
