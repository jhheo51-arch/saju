## 요청

- 참가자가 지정한 빨강 `#B82647`, 석간주 `#8A4C44`, 파랑 `#0B6DB7`, 뇌록 `#397664`, 노랑 `#F9D537`, 검정 `#1D1E23`, 흰색 `#FFFFFF`을 서비스 화면의 기준 색상으로 사용합니다.
- 후속 요청에 따라 글꼴 변경은 취소하고 기존 글꼴을 유지합니다.

## 범위와 기준

- CSS의 기존 색상 값을 위 일곱 색 및 이 색을 섞은 밝은 바탕색으로 정리합니다. 기능·데이터·해석 규칙은 바꾸지 않습니다.
- 중요한 글자와 바탕은 4.5:1 이상의 대비를 유지하고, 키보드 초점 표시와 모바일 줄바꿈을 유지합니다.
- 기존 화면에서 쓰던 본문 산세리프와 제목 명조체의 조합을 그대로 유지합니다.

## 완료 조건

- 화면의 주요 색상이 지정 팔레트에 맞고, 글꼴은 변경 전과 같습니다.
- PC·휴대전화 화면에서 글자가 읽히고 가로 넘침이 없습니다.
- 기존 자동 검사와 빌드가 통과합니다. 참가자 직접 사용 확인은 별도입니다.

- 주요 글자 대비 계산: 흰색/뇌록 5.32:1, 흰색/빨강 6.17:1, 석간주/흰색 6.57:1. 작은 제목 안내 문구는 노랑/뇌록 대비가 3.70:1이라 흰색으로 두고 노랑은 장식선에 사용했습니다.
