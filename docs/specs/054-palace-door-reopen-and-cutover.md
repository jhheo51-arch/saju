# 054-palace-door-reopen-and-cutover — 새 궁궐문과 오전 9시 운세 기준

작성일: 2026-09-28  
상태: 구현·자동 검사·Production 빌드 완료, 참가자 화면 확인 전

## 목표

- 오늘의 운세는 페이지에 새로 접근할 때마다 닫힌 문부터 보여 사용자가 매번 직접 열 수 있게 한다.
- 한국 시간 00:00~08:59에는 전날에 준비된 운세를, 09:00부터는 당일 운세를 조회한다.
- 매일 09:00 KST의 Vercel Cron은 당일 운세만 사전 생성한다.
- 기존 첨부 원화 대신 서비스의 차분한 청록·먹색·금빛·한지 질감과 어울리는 새 문 일러스트를 사용한다.

## 화면 규칙

- 문을 연 기록을 브라우저에 저장하지 않는다. 같은 사용자가 같은 날짜에 새로고침하거나 다시 방문하면 닫힌 문 버튼으로 시작한다.
- 한 번 연 현재 화면에서는 운세·색상·추천 숫자가 문 안쪽에 나타난다. 키보드 초점, `aria-expanded`, 모션 줄이기 설정은 유지한다.
- 새 문은 정확한 중앙 이음선을 기준으로 좌우 반쪽을 분리해 열며, 글자·로고·워터마크를 포함하지 않는다.

## 날짜·Cron 규칙

| 한국 시간 | 사용자에게 조회할 `fortune_date` | Cron 생성 대상 |
|---|---|---|
| 00:00~08:59 | 전날 | 실행하지 않음 |
| 09:00 이후 | 당일 | 당일 운세 생성 |

- 표시는 이 날짜를 `DailyFortune`의 날짜·색상·숫자와 동일하게 사용한다. 전날 값을 당일 값처럼 새로 만들지 않는다.
- Cron 예약식 `0 0 * * *`(UTC)는 유지한다.
- 서버의 사용자 조회 및 기본 사주 저장 직후 준비 동작도 표시 기준 날짜를 사용한다.

## 생성 자산

- 경로: `public/palace-door-ink-jade-v01.png`
- 생성 방식: built-in image generation
- 프롬프트 요약: 먹색 목재·차분한 청록 패널·고색 금빛 장식·한지 질감의 정면 대칭 한국 궁궐 양문, 글자·로고·워터마크 없음.

## 완료 조건

- 오전 8:59 KST와 오전 9:00 KST 경계에서 사용자 API가 각각 전날·당일 `fortune_date`를 사용한다.
- Cron은 오전 9시의 당일 날짜를 생성한다.
- 새로고침/재방문 때 닫힌 문을 다시 누를 수 있고, 이전 열림 기록으로 바로 열리지 않는다.
- 새 자산이 존재하고 양쪽 문짝이 좌우 배경 위치로 사용된다.
- TypeScript, 관련 자동 테스트, 품질 하네스, Production 빌드를 통과한다.
