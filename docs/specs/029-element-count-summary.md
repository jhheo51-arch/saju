# 029-element-count-summary — 오행 한눈 요약

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 확인 전

## 목적

방사형 그래프 아래 공간에 그래프의 실제 글자 수를 바로 읽을 수 있는 요약을 표시합니다.

## 범위

1. 가장 큰 글자 수를 가진 오행을 `많이 보이는 기운`으로 표시합니다.
2. 가장 작은 글자 수를 가진 오행을 `상대적으로 적게 보이는 기운`으로 표시합니다.
3. 동률인 오행은 모두 표시하며, 다섯 값이 같으면 부족한 기운을 꾸며내지 않고 `고르게 보이는 기운`으로 표시합니다.
4. 다섯 기운의 포함 여부와 최대·최소 개수 차이를 `차이 1개`처럼 보여줍니다.
5. 글자 수 비교일 뿐 좋고 나쁨이나 성격·미래를 뜻하지 않는다는 안내를 표시합니다.

## 완료 조건

- 그래프 바로 아래에 실제 계산값을 사용한 요약이 보입니다.
- `목 1·화 2·토 1·금 2·수 2`일 때 많은 기운은 `화·금·수 · 각 2개`, 상대적으로 적은 기운은 `목·토 · 각 1개`로 표시됩니다.
- 작은 화면에서도 잘리거나 가로로 넘치지 않습니다.
- 관련 검사, 전체 검사, 빌드와 로컬 화면을 확인합니다.
