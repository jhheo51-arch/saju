# 050-restore-pre-september-28-features — 기존 사주 기능 전체 복구

작성일: 2026-09-28  
상태: 구현·전체 자동 검사·빌드 완료, 로그인 화면 확인 대기

## 문제

오늘 운세 작업 브랜치가 2026-09-26의 완성 화면보다 축소된 화면을 기준으로 병합되어, 남녀 아바타 선택, 아바타 원화, 질문 답변, 출생시간 정확도, 개인 상황 입력, 최근 해석 기록, 궁궐 귀인전, 용신 카드 등 기존 기능이 사라졌습니다.

## 복구 원칙

- 2026-09-26의 마지막 완성 커밋을 기존 기능의 기준으로 복구합니다.
- 오늘 운세, DB 저장, Vercel Cron은 복원 화면 위에 추가하며 기존 기능을 대체하지 않습니다.
- 기존 로그인 사용자의 여러 `saju_results` 기록 중 가장 최근의 유효 차트를 오늘 운세 기준으로 사용합니다.
- 오늘 운세는 로그인 직후 조회하고, 정확한 출생시간으로 새 해석을 제출하면 당일 운세를 즉시 생성·저장합니다.

## 완료 조건

- 9월 28일 이전의 기존 화면·API·이미지·테스트가 복구된다.
- 남녀 아바타 선택과 이미지 저장, 질문 답변, 출생시간 선택, 개인 상황 선택, 최근 기록이 동작한다.
- 오늘 운세·색상·추천 숫자·궁궐 문·Cron 경로가 함께 동작한다.
- TypeScript 검사, 전체 자동 테스트 209개, 품질 하네스, Production 빌드가 통과한다.
- 별도 PR에서 검토·`main` 병합 후 실제 로그인 화면을 확인한다.
