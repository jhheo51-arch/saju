# 056-remove-question-answer-panel — 실패하는 질문 답변 영역 제거

작성일: 2026-09-28  
상태: 구현·자동 검사·Production 빌드 완료, 참가자 화면 확인 전

## 문제

결과 아래의 ‘궁금한 점 답변’은 별도 Gemini 호출에 의존합니다. 연결이 실패하면 빈 입력칸과 오류만 남아, 이미 완성된 사주 해석과 운세를 읽는 흐름을 방해합니다.

## 범위

- 결과 화면에서 질문 입력, 답변 받기 버튼, 저장 선택, 오류 문구와 질문 답변 카드를 제거한다.
- 브라우저가 `/api/question`을 호출하거나 질문 답변을 현재 계정 결과에 덧붙이지 않도록 관련 화면 상태와 호출 함수를 제거한다.
- 기존 계정에 저장된 질문 답변 데이터와 `/api/question` 경로는 호환성을 위해 삭제하지 않는다. 다만 서비스 화면에는 표시하지 않는다.
- 사주 해석, 계정 기록, 아바타, 오늘의 운세와 이번 주 운세는 변경하지 않는다.

## 완료 조건

- 로그인한 결과 화면에 ‘궁금한 점 답변’, 질문 입력칸, ‘질문 답변 받기’ 버튼과 질문 오류 메시지가 보이지 않는다.
- 화면 코드에 질문 전송 상태나 `/api/question` 호출이 남아 있지 않다.
- 기존 해석과 오늘·이번 주 운세 관련 자동 검사를 포함한 전체 품질 검사와 Production 빌드가 통과한다.

## 검증 기록

- 독립 검사자가 화면 코드에 질문 입력·버튼·상태·`/api/question` 호출이 남지 않는지 확인하도록 `tests/follow-up-question.test.ts`를 보강했다. 기존 서버 호환성 검사는 유지했다.
- `npm run harness` 통과: 하네스 11개 파일, TypeScript, 자동 테스트 223개, 사주 품질 평가 10/10.
- `npm run build` Production 빌드 통과.
- 실제 로그인한 운영 화면의 직접 사용 확인은 아직 남아 있다.
