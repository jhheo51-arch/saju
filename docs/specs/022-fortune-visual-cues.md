# 022 — 오늘·이번 주 운세의 시각적 단서

## 목표

`04 오늘과 이번 주 운세`를 글만 긴 영역이 아니라, 계산 근거와 바로 해볼 행동을 빠르게 읽을 수 있는 영역으로 만든다. 점신 앱의 짧은 시각 정보에서 아이디어를 얻되, 점수나 요일별 예언처럼 이 서비스가 계산하지 않는 정보는 만들지 않는다.

## 범위

1. 계산된 사주의 일간과 월주를 작은 배지로 표시한다. 배지는 **오늘·이번 주를 따로 계산한 값이 아닌, 원래 사주 풀이의 근거**라고 명시한다. 일간·월주 용어는 눌러 뜻을 볼 수 있다.
2. Gemini 응답에서 오늘과 이번 주 각각 `action` 한 문장을 구조화하여 받는다. 본문과 별도로 `한 걸음` 상자에 표시한다. 기존 저장 결과처럼 `action`이 없다면 상자를 꾸며내지 않고 생략한다.
3. 월~일 7일 날짜 띠와 해당 주의 실제 24절기 이름을 표시한다. 절기 정보는 기존 `lunar-javascript`의 절기 시각을 한국 시간으로 바꿔 계산한다. 그 주에 절기가 없다면 다음 절기의 날짜를 알려준다. 특정 요일의 운세·점수는 표시하지 않는다.

## 데이터·오류 처리

- 새 Gemini 응답의 `today.action`과 `weekly.action`은 짧고 구체적인 행동 문장이어야 한다. 서버는 빈 값·너무 긴 값을 거부한다.
- 기존 localStorage·계정 저장 결과는 `action`이 없어도 복원한다. 새 응답만 필수로 검증한다.
- 일간·월주 배지는 이미 계산·저장된 사주 차트에서만 읽는다.
- 절기는 예언이 아니라 계절을 나누는 달력 날짜임을 짧게 설명한다. 절기 계산에 실패하면 날짜 띠는 유지하고 잘못된 절기 이름을 표시하지 않는다.
- 모바일에서 7일 날짜 띠가 가로로 넘치거나 글자가 잘리지 않는다.
