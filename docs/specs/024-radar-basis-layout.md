# 024-radar-basis-layout — 방사형 그래프 중심 계산 근거 배치

작성일: 2026-09-23  
상태: 구현·자동 검증 완료, 참가자 확인 전

## 목적

`이번 풀이의 근거` 구도를 다시 정리해 방사형 그래프를 왼쪽에 크게 두고, 오른쪽에는 일간을 위에, 월주를 아래에 배치합니다.

## 범위

1. 넓은 화면은 `왼쪽 방사형 그래프 / 오른쪽 일간·월주 세로 배치`의 두 열 구조를 사용합니다.
2. 방사형 그래프 축은 `목(木)·화(火)·토(土)·금(金)·수(水)`처럼 한글과 한자만 표시하고 중복되는 숫자는 넣지 않습니다.
3. 그래프 아래의 `목 1 · 화 2 · 토 1 · 금 2 · 수 2` 배지 모양과 한글 표기는 기존 모습 그대로 유지합니다.
4. 작은 화면에서는 가로로 억지로 줄이지 않고 그래프, 일간, 월주 순서의 한 열로 바꿉니다.
5. 계산값, 오행 설명, 화면 읽기 도구용 한국어 설명과 기존 풀이·아바타·운세 기능은 바꾸지 않습니다.
6. 월주의 두 글자도 일간 이름처럼 눌러 위·아래 글자와 오행의 뜻을 확인할 수 있게 합니다.

## 완료 조건

- PC에서 그래프가 왼쪽, 일간이 오른쪽 위, 월주가 오른쪽 아래에 보입니다.
- 그래프 축은 숫자 없이 `목(木)·화(火)·토(土)·금(金)·수(水)`를 표시합니다.
- 그래프 아래 한글 숫자 배지는 기존 순서와 형태를 유지합니다.
- 작은 화면에서 잘리거나 가로 스크롤이 생기지 않습니다.
- `임진` 같은 월주 이름을 누르면 해당 두 글자의 뜻을 보여줍니다.
- 관련 독립 테스트, 전체 검사, 빌드와 로컬 화면을 확인합니다.
