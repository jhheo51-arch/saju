# 034-yongshin-balance-cards — 간이 억부용신 카드

## 목표

오행 분포 아래에서 용신·희신·기신을 첨부 참고 화면처럼 명확히 구분하되, 현재의 단순 오행 글자 수만으로 부족한 오행을 용신이라고 단정하지 않습니다.

## 요구사항

1. 판정 방식은 이번 버전에서 `간이 억부용신` 한 가지로 명시합니다.
2. 네 천간은 각 1점, 네 지지는 지장간의 본기·중기·여기를 1개면 `1`, 2개면 `0.7·0.3`, 3개면 `0.6·0.3·0.1`로 나눕니다. 월지는 계절 영향의 간이 반영으로 다른 지지의 2배를 적용합니다.
3. 일간과 같은 오행 및 일간을 생하는 오행의 합이 전체 가중치의 50% 이상이면 `신강 쪽`, 미만이면 `신약 쪽`으로 분류합니다.
4. 신강 쪽은 일간을 극하는 오행을 용신, 그 용신을 생하는 오행을 희신, 일간을 생하는 오행을 기신으로 표시합니다. 신약 쪽은 일간을 생하는 오행을 용신, 일간과 같은 오행을 희신, 일간을 극하는 오행을 기신으로 표시합니다.
5. 카드에는 역할 이름, 오행 한글·한자, 쉬운 역할 설명을 함께 표시해 색만으로 뜻을 전달하지 않습니다.
6. 판정 경향, 도움 비중, 실제 일간과 선정 근거를 표시합니다.
7. 합·충·특수격국·조후를 포함하지 않는 제한과 전통 해석의 한 가지 참고라는 안내를 화면에 항상 표시합니다.
8. 저장된 이전 결과도 네 기둥에서 다시 계산해 표시하고 저장 형식은 바꾸지 않습니다.
9. 넓은 화면은 세 카드 한 줄, 좁은 화면은 세로 목록으로 표시하며 가로 스크롤이 생기지 않습니다.
10. 기존 오행 색을 이어 쓰되 금은 따뜻한 중성 회색, 수는 채도가 높은 깊은 파랑으로 표시해 두 색이 서로 비슷해 보이지 않게 합니다.

## 확인 기준

- [x] 지장간과 월지 가중치가 명세대로 계산됩니다.
- [x] 신강·신약 사례에서 용신·희신·기신 관계가 명세와 일치합니다.
- [x] 일간이 달라지면 세 오행이 실제 생극 관계에 따라 달라집니다.
- [x] 화면에 세 역할·한글·한자·쉬운 설명·판정 근거·제한 안내가 보입니다.
- [x] 색을 보지 않아도 세 역할을 구분할 수 있고 모바일에서 한 열로 표시됩니다.
- [x] 기존 전체 검사와 프로덕션 빌드가 통과합니다.
- [ ] 로그인 후 실제 결과 화면을 참가자가 직접 확인합니다.

## 구현 메모

- 계산은 `lib/saju/yongshin.ts`, 표시는 `app/yongshin-summary.tsx`에서 분리합니다.
- 기존 저장 결과의 `chart.pillars`를 사용하므로 데이터베이스 구조 변경은 없습니다.
- 독립 테스트 10개에서 지장간·월지 가중치, 50% 경계, 다섯 일간의 신강·신약 관계, 실제 계산 사례, 이전 결과 호환, 카드 내용, 모바일 배치, 금·수 색상 거리를 확인했습니다.
- 금은 `#59514a / #f4f0ec`, 수는 `#155f9b / #deefff`를 그래프·용신 카드·운세 배지에 동일하게 적용했습니다. 금·수의 전경·배경 색상 거리와 각 배경 위 글자 명암비도 검사했습니다.
- 계산 제한 안내는 핵심을 유지하면서 넓은 화면에서 한 줄로 읽히도록 줄였고, 글자 크기는 14px로 높였습니다. 작은 화면에서는 가로 넘침 없이 자연스럽게 줄바꿈합니다.
- 안내 문구 관련 독립 검사 9/9, 전체 `npm run check` 171/171과 `npm run build`가 통과했습니다.
- 전체 `npm run check` 170/170, `npm run build`, `git diff --check`가 통과했습니다. 로그인 후 실제 결과 화면의 참가자 직접 확인은 남았습니다.
