# 018-element-graph-section — 독립된 03 오행 그래프 영역

작성일: 2026-09-23  
상태: 구현·자동/로컬 검증 완료, 참가자 직접 확인 전

후속 변경: 사용자가 큰 그래프 제거를 요청해 `020-weekly-fortune-no-graph.md`에서 화면 표시를 대체합니다. 이 문서는 당시 버전 기록으로 보존합니다.

## 목적

‘02 나의 사주 이야기’처럼 번호와 제목이 있는 독립된 `03` 영역을 만들고, 계산된 사주를 쉽고 재미있게 한눈에 봅니다.

## 이번 범위

- `02`는 계산 근거·성향·선택 주제 풀이를 담습니다.
- `03 나의 사주를 그림으로`는 기존 계산 결과의 목·화·토·금·수 글자 수를 8칸 그래프로 보여줍니다. 각 칸은 여덟 글자 중 한 글자를 뜻합니다. 다섯 줄의 채운 칸 합계는 8이며, 모든 줄에 이름과 숫자를 직접 적습니다.
- 기존 아바타는 그래프 아래의 같은 `03` 영역에 배치합니다. 오늘의 운세는 별도 `04` 영역으로 분리합니다. 저장·계산·AI 요청 형식은 바꾸지 않습니다.
- 0개도 빈 칸과 `0개`로 보입니다. 글자 수로 성격의 강약·건강·미래를 단정하지 않는 안내를 둡니다.
- 좁은 화면과 키보드·화면 읽기 도구에서도 그래프의 이름과 값이 읽히도록 합니다. 색은 보조 수단입니다.

## 완료 조건

- 결과에서 `02`, `03`, `04`가 각각 독립된 영역으로 나타납니다.
- 그래프의 다섯 값이 `chart.elements`와 일치하고 합계가 8입니다. 저장 결과를 다시 열어도 동일하게 보입니다.
- 아바타·오늘의 운세·계산 원자료·저장/삭제가 기존처럼 작동합니다.
- 자동 검사, 빌드, PC·모바일 로컬 화면을 확인합니다. 참가자 직접 사용 확인은 별도입니다.

## 검증 기록

- `02`는 풀이와 원자료, `03`은 오행 칸 그래프와 아바타, `04`는 오늘의 운세인 독립 카드로 분리했습니다. 기존 저장 형식과 AI 요청은 바꾸지 않았습니다.
- 계산된 오행 값으로 다섯 줄·여덟 칸을 만들고, 각 줄의 이름·자연 비유·숫자를 직접 표시합니다. 0개는 빈 칸으로 남습니다.
- `npm run check`: 타입 검사와 자동 테스트 79/79 통과. `npm run build`: 통과.
- `localhost:3000`의 PC 및 375px 화면에서 독립된 03 카드, 다섯 줄 그래프, 아바타와 04 카드, 가로 넘침 없음을 확인했습니다. 저장된 결과를 불러왔을 때도 그래프가 표시됐습니다.
- 참가자 직접 사용 확인은 남아 있습니다. 이 대화에서는 독립 테스트 작성자를 사용할 수 없어 상태표 체크는 보류합니다.
