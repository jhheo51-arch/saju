# 019-avatar-copy-and-simple-background — 아바타 문장과 배경 다듬기

작성일: 2026-09-23  
상태: 구현·자동/로컬 검증 완료, 참가자 직접 확인 전

## 요청

- 아바타의 `맡은 일` 등 긴 설명에서 `요.`처럼 한 글자만 다음 줄로 떨어지지 않게 합니다.
- 복잡한 궁궐 풍경 대신 캐릭터가 잘 보이는 단순하고 귀여운 배경을 표시합니다.

## 범위

- 아바타 정보 문장의 한글 단어는 가능한 한 통째로 줄바꿈하고, 아주 좁은 화면에서만 긴 단어를 안전하게 나눕니다. 글자를 줄이거나 잘라 숨기지 않습니다.
- 기존 배경 이미지 파일은 보존하되 화면의 배경 이미지 참조만 제거합니다. 배경은 부드러운 하늘·해·언덕의 간단한 CSS 그림으로 만듭니다. 아바타 원화와 계산·해석·저장 값은 바꾸지 않습니다.
- PC와 375px 화면에서 읽기와 가로 넘침을 확인합니다.

## 완료 조건

- 제공된 사례의 문장 끝 `요.`가 단독 줄에 남지 않고, 다른 역할 설명도 읽을 수 있습니다.
- 아바타 원본이 단순한 배경 위에 보이고 기존의 복잡한 풍경은 화면에 나오지 않습니다. 원본 배경 파일은 남습니다.
- 자동 검사와 빌드가 통과합니다. 참가자 직접 확인은 별도입니다.

## 검증 기록

- 아바타 설명에 한글 단어 우선 줄바꿈과 보기 좋은 문단 줄바꿈을 적용했습니다. 아주 좁은 화면에서는 긴 단어를 안전하게 나눌 수 있습니다.
- 화면의 복잡한 풍경 참조를 제거하고 CSS의 연한 하늘·해·언덕으로 배경을 바꿨습니다. `public/avatars/saju-landscape.png` 원본 파일은 보존했습니다.
- `npm run check`: 81/81 통과. `npm run build`: 통과. 기존 아바타 테스트가 과거 정보 항목을 찾던 부분은 현재 궁궐 이야기의 세 항목에 맞춰 고쳤습니다.
- `localhost:3000`의 375px 화면에서 제공된 ‘맡은 일’ 사례의 끝 `역할이에요.`가 함께 줄바꿈되고, 단순한 배경 뒤에서 아바타가 보이며 가로 넘침이 없음을 확인했습니다. 참가자 직접 확인은 남아 있습니다.
