# 027-yinyang-season-grounding — 음양 분포와 월지 계절 근거

작성일: 2026-09-23  
상태: 구현·자동·로컬 화면 검증 완료, 참가자 사용 확인 전

## 목적

현재의 일간·월주·오행 개수에 더해, 기존 네 기둥에서 직접 확인할 수 있는 음양 분포와 월지의 전통 계절 구간을 풀이 근거로 제공합니다.

## 근거 자료와 적용 한계

- 산둥대학교 관련 학술 자료는 천간을 `갑·병·무·경·임=양`, `을·정·기·신·계=음`, 지지를 `자·인·진·오·신·술=양`, `축·묘·사·미·유·해=음`으로 정리하고, `인묘진=봄`, `사오미=여름`, `신유술=가을`, `해자축=겨울`의 전통 계절 구간을 설명합니다.
  - https://zhouyi.sdu.edu.cn/__local/5/9A/8B/CB8DA70DF8DE5BD726CC885B223_85267DBF_1C8288.pdf
- 한국민족문화대백과사전은 음양을 서로 반대이면서 의존하는 흐름으로 설명하고, 오행을 고정 물질보다 변화의 과정으로 설명합니다.
  - https://encykorea.aks.ac.kr/Article/E0043032
- 같은 사전의 사주 항목에는 네 천간과 네 지지 각각의 음양을 표로 표시한 예가 있습니다.
  - https://encykorea.aks.ac.kr/Article/E0025957
- 이는 전통 해석 체계의 분류이며 과학적 성격 검사나 미래 예측값이 아닙니다. 계절은 실제 출생지의 날씨가 아니라 월지에 대응하는 전통 달력 구간입니다.

## 범위

1. 네 기둥의 천간·지지 여덟 글자를 위 고정 표로 분류해 `음 n개·양 n개`를 계산합니다. 합계는 항상 8이어야 합니다.
2. 월주의 아랫글자(월지)를 고정 표로 분류해 `봄·여름·가을·겨울`과 `○월`을 계산합니다.
3. 결과 화면의 `이번 풀이의 근거`에 두 값을 짧은 사실 카드로 표시합니다.
4. Gemini에는 계산된 값만 전달하고, 주제 풀이의 `계산 근거`와 `쉬운 뜻`에 정확한 음양 개수와 계절 구간을 쓰게 합니다.
5. 서버는 새 Gemini 결과에 정확한 두 값이 포함됐는지 검사합니다. 빠지거나 다른 값이면 결과를 표시하지 않습니다.
6. 음양 개수만으로 성격의 강약·좋고 나쁨을 정하지 않고, 계절만으로 사건·건강·직업을 예측하지 않습니다.
7. 십성·지장간·대운·합충형파해 등 추가 관계 계산은 이번 범위에서 제외합니다.
8. 이전 저장 결과는 그대로 읽으며, 화면의 두 계산값은 저장된 네 기둥에서 다시 계산합니다.

## 완료 조건

- 공개 기준 사례를 포함해 음·양 합계가 8이고 월지 계절 매핑이 정확합니다.
- 화면에 정확한 음양 개수와 계절 구간, 비단정 안내가 표시됩니다.
- Gemini 전달 자료와 결과 검증이 실제 계산값을 사용하며 잘못된 값은 거절합니다.
- 이전 저장 결과를 깨지 않고 관련 독립 테스트, 전체 검사, 빌드, PC·모바일 화면 확인을 마칩니다.

## 검증 기록

- 천간 10자·지지 12자의 음양 분류와 월지 12자의 사계절 매핑을 독립 검사했고, 공개 기준 사례에서 `음 4·양 4`, `겨울(자월)`을 재현했습니다.
- Gemini 전달 자료가 원본 생년월일·출생시간 없이 계산값만 담는지, 결과의 정확한 근거가 빠지거나 다른 값이면 거절하는지 검사했습니다.
- `음 4·양 4`를 성격의 균형·조화로 확대 해석한 응답은 거절하고, 개수는 능력의 우열을 뜻하지 않는다는 응답은 허용함을 검사했습니다.
- 전체 자동 검사 `132/132`와 배포용 빌드가 통과했습니다.
- 실제 Gemini 생성 결과에서 `신금, 무자(토·수), 음 4·양 4, 겨울(자월)` 근거와 비단정 안내가 함께 표시되는 것을 확인했습니다.
- 저장 결과를 새로고침해 두 계산값이 다시 표시되는 것을 확인했고, 375px 모바일 화면에서 한 열 배치와 가로 넘침 없음도 확인했습니다.
- 참가자의 직접 사용 확인과 외부 배포는 아직 하지 않았습니다.
