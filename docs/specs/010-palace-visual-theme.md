# 010-palace-visual-theme — 궁궐 분위기의 화면 디자인

작성일: 2026-09-23  
상태: 한옥형 스타일 재작업·자동 검사·로컬 화면 확인, 독립 테스트 및 참가자 사용 확인 전

## 요청과 방향

참가자가 제공한 조선시대 궁 사진 세 장의 붉은 기둥, 청록색 단청, 어두운 처마, 밝은 바닥을 참고해 기존 사주 화면의 시각적 분위기를 바꿉니다. 사진 파일을 서비스에 직접 넣거나 사주 계산·로그인·저장 흐름을 변경하지 않습니다.

## 범위

- 별도 CSS 파일에서 색상, 제목 영역, 카드 테두리, 버튼과 입력 선택 상태를 조정합니다.
- 단청 색은 제목 장식과 구분선에 제한하고, 해석 본문은 밝은 한지색 바탕과 진한 글자로 읽기 쉽게 유지합니다.
- 휴대전화 너비와 키보드 초점 표시를 유지합니다. 장식은 의미 전달에 사용하지 않습니다.
- 후속 수정: 직선형 지붕과 전면 격자 측면은 궁궐 건축처럼 보이지 않는다는 참가자 피드백을 반영합니다. 제목 위에는 완만한 곡선의 기와 처마와 단청 받침을, 양옆에는 목재 기둥과 부분 창호 장식을 둡니다. 제목 문구도 서비스의 이름인 ‘나만의 사주 이야기’로 명확히 합니다.

## 완료 조건

- 첫 화면에서 궁궐의 붉은 기둥·청록 처마·한지 바탕이 느껴집니다.
- 날짜·시간·주제 입력과 결과 카드, 오류·저장 안내, 용어 설명을 기존처럼 읽고 조작할 수 있습니다.
- 자동 검사와 PC·모바일 화면 검토를 기록합니다. 참가자 사용 확인은 별도입니다.

## 검증 기록

- `app/palace-theme.css`를 별도로 만들어 기존 `app/globals.css`를 보존하고 `app/layout.tsx`에서 불러오게 했습니다. 첨부 사진의 색을 CSS 장식으로 번안했고 사진 파일은 서비스에 복사하지 않았습니다.
- `npm run check`: 타입 검사와 기존 자동 테스트 62/62 통과. `npm run build`: 통과. `git diff --check`: 공백 오류 없음.
- `http://localhost:3000/`에서 기본 너비와 375px 휴대전화 너비의 제목·입력 화면을 확인했습니다. 풀이 카드와 계산 근거 영역도 로컬 화면에서 확인했습니다.
- 이 대화에서는 독립 테스트 작성자를 사용할 수 없어 프로젝트 작업 원칙의 해당 검증을 마치지 못했습니다. 따라서 상태표 체크는 보류합니다. 참가자의 직접 사용 확인도 남았습니다.
- 참가자 피드백: 기존 색은 유지하되 줄무늬 띠가 한옥처럼 보이지 않고 양옆이 허전함. `app/palace-theme.css`의 상단을 어두운 기와지붕 실루엣과 목재 틀로 교체하고, 넓은 화면 양옆에 한지 창호·나무 문살 장식을 추가했습니다. 1200px 이하에서는 측면 장식을 숨깁니다.
- 재검증: `localhost:3000` 기본 너비에서 지붕·양옆 창호·입력 카드, 375px 너비에서 지붕·입력 영역을 눈으로 확인했습니다. `npm run check` 64/64 통과, `npm run build` 통과. 참가자 확인과 독립 테스트는 여전히 남았습니다.
- 추가 피드백에 따라 직선형 지붕과 전면 격자 장식을 다시 교체했습니다. `public/hanok-eaves.svg`는 완만한 용마루·기와 반복·들린 처마·단청 받침을 그린 장식이고, `public/hanok-column.svg`는 양옆의 붉은 목재 기둥과 단청 공포 장식입니다. 제목은 ‘나만의 사주 이야기’로 바꾸고, 작은 화면에서 한 글자만 따로 떨어지지 않게 했습니다. Figma 파일이나 외부 게시물은 만들지 않았습니다.
- 최종 자동 확인: SVG 두 파일을 XML로 읽는 검사 통과, `npm run check` 69/69 통과, `npm run build` 통과, `git diff --check` 공백 오류 없음. `localhost:3000`의 기본 너비와 375px에서 지붕·제목·측면 장식 표시를 눈으로 확인했습니다. 독립 테스트와 참가자 직접 사용 확인은 남아 있어 상태표는 아직 체크하지 않습니다.
- 최신 피드백(2026-09-23): 참가자가 지붕과 측면 기둥을 모두 빼고 지붕의 색감만 쓰기로 결정했습니다. 해당 장식 SVG 두 파일과 CSS 참조를 제거했습니다. 현재 화면은 청록색 제목 영역, 적갈색 버튼·강조선, 금색 가는 선, 밝은 바탕을 사용하며 건축물 형태를 그리지 않습니다. `localhost:3000`의 기본/375px 화면에서 제거를 확인했고, `npm run check` 69/69와 `npm run build`가 통과했습니다. 독립 테스트와 참가자 직접 확인은 남아 있습니다.
