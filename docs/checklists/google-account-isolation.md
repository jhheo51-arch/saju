# Google 계정·결과 분리 확인

실제 Google 계정 A와 B의 소유자가 로컬 또는 배포 주소에서 직접 확인합니다. 이메일, 토큰, 생년월일은 이 문서에 적지 않습니다.

## 준비

- Supabase에 `20260926000100_expand_saju_result_history.sql`을 적용합니다.
- Google 제공자와 현재 사이트의 Redirect URL을 확인합니다.
- 브라우저 프로필 또는 시크릿 창 두 개를 준비합니다.

## 계정 A

- [ ] Google 로그인 후 원래 화면으로 돌아온다.
- [ ] 정확한 시간, 대략적인 시간대, 모름으로 각각 결과를 만들 수 있다.
- [ ] 최근 결과 목록에 새 결과가 최신순으로 보인다.
- [ ] 질문 답변 저장을 끈 경우 새로고침 후 답변이 남지 않는다.
- [ ] 저장을 켠 경우 답변만 남고 질문 원문은 저장되지 않는다.
- [ ] 개별 삭제와 전체 삭제가 실제 목록에 반영된다.

## 계정 B와 분리

- [ ] 계정 B 로그인 직후 계정 A의 결과가 보이지 않는다.
- [ ] 계정 B가 만든 결과는 계정 A로 다시 로그인했을 때 보이지 않는다.
- [ ] 로그아웃 즉시 결과와 기록 목록이 화면에서 사라진다.
- [ ] 만료된 세션으로 API를 호출하면 401이며 Gemini가 호출되지 않는다.

## 데이터 확인

- [ ] `saju_results`에 원본 생년월일·출생시간·질문 원문·토큰 열이 없다.
- [ ] RLS가 켜져 있고 모든 CRUD 정책이 `auth.uid() = user_id`를 사용한다.
- [ ] 사용자별 10건을 넘긴 오래된 결과가 정리된다.

완료 날짜와 확인자만 Spec 043·045의 검증 기록에 남기고 계정 식별 정보는 기록하지 않습니다.
